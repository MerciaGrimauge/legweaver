# LegWeaver エディター拡張・Blender 処理 設計書

この文書は、エディター拡張（C#）と Blender 内で動く処理（Python）の働きを、設計書として自分の言葉で書いたものです。コードの写しは含みません。シェーダーと実行時の部品は [algorithm_shader_runtime.md](algorithm_shader_runtime.md) の対象で、ここではそれらとの境界だけを書きます。処理の仕様を実装できる粒度で網羅した説明は同じフォルダに並ぶ `ALGORITHM.md` にあり、本書はその設計上の構成と取り決めを中心にまとめます。

- 長さの単位: 特に断らない限り、mm・m は実寸です。Blender 側の計算は「体のメッシュの単位」（以下、メッシュ単位）で行い、実寸 x mm は `x / 1000 / (1 メッシュ単位あたりのメートル数)` に換算します。
- 「脚の座標」: 股関節 0・膝 1・足首 2・つま先の骨 3 とする、脚の骨に沿った位置の数（第 4 章で定義）。腕では肩 0・肘 1・手首 2・中指の付け根 3。
- 括弧内の関数名・ファイル名は参照用で、仕様の一部ではありません。

## 1. 全体の目的と入出力

### 1.1 目的

VRChat などで使う Humanoid アバターに、体の形にぴったり沿った衣類を自動で作って着せます。布は体の肌の面そのものを外へ押し出して作るので、どの頂点も肌の一点に結び付き、その点のボーンウェイトとシェイプキーをそのまま受け継ぎます。そのため、どの姿勢でも肌と同じように曲がります。

衣類の種類は次の 10 種です。

| 分類 | 種類 | 要点 |
|---|---|---|
| 脚 | タイツ、スパッツ、サイハイ、ニーハイ | Blender で作る。ニーハイはサイハイと同じ作り方で上端だけ違う |
| 腕 | 手袋、アームカバー | Blender で作る（第 9 章） |
| 包む | 包む | 脚の代わりの下半身（おばけのしっぽなど）を、その形のまま布で包む。Blender を使わない（第 9.3 節） |
| 補強 | 親指サック | 足の親指だけを覆う。タイツの下に着る物として、肌との隙間を 0.3 mm 以下に抑える（第 4.5 節） |
| 小物 | ガーター、レッグラップ | 脚に付ける帯・らせんのリボン。素肌の上、または前に作ったタイツ・靴下やアバター自身の脚の服の上に付ける（第 4.6 節・第 5.12 節・第 8.6 節）。ガーターにはリボンの結び目を付けられ、垂れは揺れ物で揺れる |

### 1.2 ユーザーの操作

1. メニューから専用のウィンドウを開き、アバターのルート（シーン上の物、またはプレハブアセット）を指定する。プレハブアセットならシーンに置いてから処理する（アセットは書き換えない）。
2. ボディメッシュは空欄なら自動で選ぶ（第 3 章）。
3. 種類・色・デニール・質感・各部の構造・柄などを設定する。
4. 「生成」を押す。Blender が裏で動き、終わると結果がアバターに装着される。

### 1.3 主な設定項目（意味だけ）

| 分類 | 項目 | 範囲・既定 |
|---|---|---|
| 種類 | タイツ／スパッツ／サイハイ／ニーハイ／手袋／アームカバー／包む／親指サック／ガーター／レッグラップ | 既定 タイツ |

設定は値のほかに「設定から決まる判定」（不透明か、見た目が透けるか、肌の写しを使うか、肌を消すか、姿勢の伸びを使うか。第 6.4 節）を持ち、各部はこれを見て振る舞いを決めます。

### 1.4 出来上がる物

- 出力フォルダ `Assets/LegWeaver_Output/{アバター名}_{物の名}_{日付}_{時刻}` に、メッシュ、マテリアル、テクスチャ（視線角度の透け、伸びのランプ、柄）、肌の写しのメッシュとマテリアルを保存する。物の名は「種類のラベル_デニールD」（ラベルは `Tights` `Spats` `ThighHighs` `KneeHighs` `Gloves` `ArmCovers` `ToeCaps` `Garters` `LegWraps`。包む種類は `Wrap`）。
- アバターの中に衣装のオブジェクト（骨の写し＋スキンメッシュ `…_Mesh`、肌の写しがあれば `…_Skin`）を作り、Modular Avatar があれば衣装として結線する。
- Avatar Optimizer（AAO）があれば、隠れる肌を消す箱の部品をボディに付ける。
- 必要なら、肌の一部のウェイトを書き換える独自の部品（ビルド時に働く）を付ける。
- ガーターのリボンがあれば、垂れごとに骨を足し、根元に VRChat の揺れ物を付ける。
- 完了の文には、アバター全体（表示中のメッシュ）の三角形数と、VRChat の PC のポリゴン数のランクの目安（32,000 まで Excellent、70,000 超で Very Poor）も出す。

## 2. 処理の流れ

### 2.1 全体

```
[Unity] 設定を写す → 体を読む → (シュリンク形状を 0 に) → (下に着ている物・上に着ている物の検出と高さ)
        → 作業フォルダに input.bin / under.bin / job.json を書く
        → Blender の版を確かめる → Blender をバックグラウンドで起動
[Blender] 体を読む → 覆う範囲を切り出す → 包絡面（SDF）を作る → 肌から浮かせる
        → つま先を差し替える → 面の崩れを直す・部位分け・下着の上に乗せる（小物: 下の層に載せる・リボン）
        → 縁に厚み → output.bin / output.json を書く
[Unity] 結果を読む → メッシュを組む（ウェイト・シェイプキー・UV）→ マテリアル
        → 肌の写し → 装着 → 姿勢伸びのデータ → 揺れ物 → 肌の削除 → 作業フォルダを消す
```

### 2.2 Unity 側の開始処理

1. アバターのルートに Humanoid の Animator があることを確かめる。指定されたボディ・包む対象が、そのアバターのシーン上の子であることを確かめる（別のアバターやアセットは拒む）。
2. 包む種類なら第 9.3 節の処理へ分かれる（Blender を使わない）。
3. ボディを決め（第 3 章）、体を読む。
4. 設定は JSON に書いて読み戻すことで丸ごと写す（生成中にウィンドウの値が変わっても影響しない）。
5. 「シュリンク系を 0 に」がオンなら、第 7.6 節の判定で見つかった形状キーの値を 0 にする（元に戻す操作の対象）。
6. 衣装を考慮するなら第 8 章の検出と高さ計算を行う。ガーター・レッグラップでは、前に作った脚の衣類とアバター自身の脚の服も下の層に加える（第 8.6 節）。
7. 作業フォルダ（プロジェクトの一時フォルダ `Temp/LegWeaver` の下、日時＋乱数 6 桁の名前）を作り、入力ファイルを書く（第 10 章）。
8. Blender の版と同梱 Python の版がサポート期間内か確かめ（第 2.4 節）、駄目なら止める。
9. Blender を起動する。開始の途中で失敗したら、作業フォルダ（体の生のメッシュを含む）を消してから例外を伝える。

### 2.3 Blender の起動と監視

- コマンド: `blender -b --factory-startup --python <主スクリプト> -- <job.json>`。
- 主スクリプトは、エディター用アセンブリ定義の GUID からフォルダを引き、その下の `Blender` フォルダにある物を使う（名前で探すと他パッケージの同名ファイルを拾うため）。無ければ「インストールが壊れている」として止める。
- 標準出力・標準エラーを別スレッドで受け、エディターの更新ごとにログへ移す。`[LW] ` で始まる行を最新の進み具合として表示する。ログは末尾 200,000 文字まで保ち、ウィンドウには末尾 15,000 文字を出す。
- 経過時間が打ち切り時間を超えたらプロセスを止め、「打ち切り」として報告する。終了後、`output.json` が無ければ失敗、`ok` が偽なら Blender 側のエラー文を報告する。
- 終了を検知したら、非同期の出力を読み終えるまで待ってから手放す（最後の行の品質の報告や失敗の内容が欠けないように）。

### 2.4 Blender の検出と版の判定

- 検出: 利用者が指定した場所が Blender の配置（隣に「5.2」のような版のフォルダがあり、その下に scripts がある）であればそれを使う。そうでなければ Windows のインストール済みプログラムの登録（コンピューター全体の 64/32 ビット、ユーザー）から表示名が「Blender」で始まる物を集め、インストール先の `blender.exe` が Blender の配置であれば候補とし、表示上の版が最も新しい物を選ぶ。無ければ Program Files（64 ビット・32 ビット）の「Blender Foundation\Blender*」の中で、フォルダ名の数字が最も大きい物。
- 版: Blender の版は `blender.exe` の隣の「数字.数字」フォルダの最も新しい物。同梱 Python の版は、その版のフォルダの `python\bin` にある `python3NN.dll` の名前から 3.NN と読む（利用者が python.exe を指定すればその隣を先に見る）。
- 判定（表はツールに内蔵、ネットは使わない）:
  - Blender の主版が 5 未満なら不可。
  - 表のサポート終了日まで 90 日以内（過ぎた物も）なら不可、180 日以内なら警告。
  - 表に無い版: 表のどれより新しければ警告（終了日が未知）、そうでなければ不可。
  - Blender と Python の判定の重い方を採る。

| Blender | サポート終了 |
|---|---|
| 5.0 | 2026-03-17 |
| 5.1 | 2026-07-14 |
| 5.2（LTS） | 2028-07-14 |

| Python | サポート終了 |
|---|---|
| 3.9 | 2025-10-31 |
| 3.10 | 2026-10-31 |
| 3.11 | 2027-10-31 |
| 3.12 | 2028-10-31 |
| 3.13 | 2029-10-31 |
| 3.14 | 2030-10-31 |

### 2.5 Blender 側の段

Blender 側は 7 段の処理を順に行い、段の間で共有するデータをひとまとめにして受け渡します（設定できる名前を限った器で、綴りの誤りを設定した所で見つける）。例外が起きたら、エラー文と追跡情報を `output.json` に書きます（`ok` は偽）。バイトコードのキャッシュは作りません（フォルダが Unity プロジェクトの中にあるため）。

1. 体を読む（第 3.4 節）
2. 覆う範囲を切り出す（第 4 章）
3. 包絡面を作る（第 5.2 節）
4. 肌から浮かせる（第 5.3〜5.5 節）
5. つま先を差し替える（第 5.6 節。まとめ・足袋型のときだけ）
6. 面の仕上げ・部位分け・下着の上・小物の下の層・リボン（第 5.7〜5.9 節、第 5.11〜5.13 節、第 6.1 節、第 8.4 節）
7. 厚みを付けて書き出す（第 5.10 節、第 7.1 節、第 10 章）

### 2.6 Unity 側の仕上げ

1. 結果の JSON と bin を読み、大きさが件数と正確に合うか確かめる（第 10 章）。
2. 出力フォルダを作り、メッシュを組んで保存する（第 7 章）。
3. マテリアルを作る（第 6 章）。
4. 肌の写しを作る（第 7.4 節）。
5. 装着する（第 7.5 節）。ガーター・レッグラップは影を受けない設定にする（数 mm 下のタイツの面の影が帯の上でまだらになるため）。
6. 姿勢で透けを変えるシェーダーを使うなら、そのためのデータをメッシュに書く（第 6.6 節）。
7. ガーターのリボンの垂れがあれば、骨と揺れ物を足す（第 7.8 節）。
8. 肌の削除の条件を満たせば、削除の箱を付ける（第 7.7 節）。
9. 作業フォルダを消す（キャンセル・失敗・ウィンドウを閉じた時も消す。消せない時は Unity の一時フォルダ掃除に任せる）。
10. 完了の文（頂点数・三角形数・同期したシェイプキー数・揺れ物の本数・重ねた衣装・0 にしたシュリンク形状・削除の箱の数・アバター全体の三角形数・保存先）を表示し、結果を選択状態にする。

## 3. 体の読み取り

### 3.1 ボディメッシュの選び方（自動）

アバターの中のスキンメッシュ（このツールが作った物＝メッシュが出力フォルダにある物を除く）を次のように順位付けし、先頭をボディとします。

1. 各メッシュについて、骨を「太もも（左右の大腿骨とその子孫のうち、下腿の子孫でない物）」「膝下（下腿とその子孫）」「その他」に分け、頂点ごとに太もも側・膝下側のウェイトの和を求める。和が 0.5 以上なら、その部分の頂点とする。骨は第 3.2 節の対応で「アバター自身の骨」に読み替える。
2. 点数 = 太もも頂点数と膝下頂点数の小さい方。0 なら候補外（靴・膝下ソックス・短パンは片方しか覆わないので点が低い）。
3. 脚の頂点から最大約 3,000 点を等間隔で取り、各点の今の姿勢での位置と、その骨の線分（太もも: 股関節→膝、膝下: 膝→足首）からの距離を記録する。
4. 「表示されている（有効で、自身からルートまでの親が全て有効）」物を先に、隠れている物を後にして、それぞれの組の中で:
   - 標本点が 20 点以上ある物どうしで、「A が B の外側にある」を判定する: A の各点に、B の点のうち 2 cm 以内で最も近い物を対応させ、対応が 20 点以上あり、その 6 割以上で A の骨からの距離が B より 0.1 mm 以上大きければ外側。
   - どの相手の外側にもない物（いちばん内側＝肌）を点数順に並べ、残りを点数順に後ろへ付ける。

ウィンドウでは、選んだボディについて次の警告を出します。

- 脚の肌の範囲（第 3.5 節）で、上端が股関節から膝への 0.1 より下で始まる → 「腰から太ももの上の肌がない」。下端が足首から膝への 0.15 より上で終わる → 「膝下の肌が途中まで」。
- 脚の肌の色が他の肌と大きく違う（第 6.8 節の色差が 20 を超える）→ 「テクスチャにタイツや靴下が描かれている可能性」。

### 3.2 骨の対応（衣装が自前の骨を持つ場合）

アバターの骨格の根（Hips の親。Hips がアバター直下か親を持たないなら Hips 自身）を基準に、メッシュが参照する骨を「アバター自身の骨」に対応させます。

1. その骨が骨格の根の下にあれば、そのまま。
2. Modular Avatar の「骨格の結合」部品の下にあれば、その部品から骨までの経路の各段の名前から接頭辞・接尾辞を外し、結合先からたどった骨（Modular Avatar 自身の対応付けの規則に従う）。
3. それ以外は、骨格の中の同じ名前の骨（幅優先で最初に見つかった物）。無ければ対応なし。

### 3.3 Unity 側で読む体のデータ

| データ | 内容 |
|---|---|
| 頂点・法線・UV | メッシュ空間（バインド空間）のまま。法線・UV が無ければ 0 で埋める |
| 三角形 | 三角形トポロジーのサブメッシュを順に連結 |
| 脚の重み | 頂点ごとに、「Hips とその子孫のうち背骨以下を除いた骨」のウェイトの割合（腰も含む） |
| 関節の混ざり | 1 − 最大ウェイト／ウェイトの和（1 本の骨だけなら 0、関節で最大 0.5 程度） |
| 足の指の番号 | 足の指ごとに骨を持つ体だけ: 左右の Toes の子ごとの枝を指とし、頂点のウェイトの半分より多くを持つ指の番号（無ければ 0）。指の骨→番号の表も持つ |
| 目印 | Humanoid の骨の位置をメッシュ空間で（下表） |
| 1 単位あたりのメートル | 左の太ももの長さ（シーン上）÷ メッシュ空間での長さ（メッシュ空間の長さが 0 に近ければ 1） |

目印の骨: Hips、Spine、Chest（無ければ UpperChest）、左右の UpperLeg・LowerLeg・Foot・Toes・UpperArm・LowerArm・Hand、左右の中指の付け根と先の関節、人差し指の付け根、親指の付け根と中間の関節。

目印のメッシュ空間の位置: その骨がメッシュの参照する骨にあれば、その骨のバインドポーズの逆行列で原点を写す。無ければ親をたどり、最初に見つかった参照骨のバインドポーズの逆行列で、その骨から見た目的の骨の位置を写す。Hips・左右の UpperLeg・LowerLeg・Foot が無ければ失敗、Chest と Spine の両方が無くても失敗。

### 3.4 Blender 側の体の前処理

1. 入力を件数どおりに読む（第 10 章）。範囲の検査: 1 単位あたりのメートルが正、計算の細かさ 0.4〜2 mm、肌との隙間 0.2〜5 mm、厚み 0.05〜5 mm の外なら失敗（手で書き換えたジョブで記憶を使い果たさないため）。
2. 溶接: 体の境界箱の対角長 × 1e-7 を刻みとして位置を量子化し、同じ位置の頂点（UV の継ぎ目で分かれた物）を 1 つにまとめる。まとめた頂点の脚の重み・関節の混ざり・下の衣装の高さ・足の指の番号は最大値、上の衣装の高さは正の物の最小値（無ければ無限大）。ガーター・レッグラップでは体の頂点ごとの下の層の高さを使わず 0 にする（向かいの脚に当たるなどでばらつき帯が凸凹になるため。下の層へは仕上げの後に面から直接測って載せる。第 5.12 節）。
3. 溶接後に退化した三角形（同じ頂点を 2 つ含む）を除く。
4. 基準の向き:
   - 腰の中心 = 左右の股関節の中点、足首の中心 = 左右の足首の中点。
   - 上 = 足首の中心 → 腰の中心 の単位ベクトル。
   - 横 = 右股関節 → 左股関節 から上の成分を除いた単位ベクトル（左向き）。
   - 体の前 = 足→つま先の骨の平均（水平化）。無ければ 上×横。
   - 頂点の左右: 腰の中心から横方向に正なら左（+1）、そうでなければ右（−1）。
5. 体の面: 最近点探索の木（BVH）と、面積重み付きの頂点法線を用意する。体の一点への「結び付け」は、最近点の三角形番号・重心座標（0〜1 に切り詰めて正規化）・最近点の位置の組。その点の法線は、3 頂点の法線を重心座標で補間して正規化した物。
6. ガーター・レッグラップでは、部位分けの設定（ウエストバンド・ランガード・パンティ部）を全てオフにし、帯の位置を股の底より下へ調整する（第 4.6 節）。

### 3.5 脚の肌の範囲（警告用）

左右の脚それぞれで、大腿骨とその子孫のウェイトの和が 0.5 以上の頂点の高さ（アバターの上方向）の最大・最小を取り、上端 = (股関節の高さ − 最大)／(股関節 − 膝) を 0〜1 に、下端 = (最小 − 足首の高さ)／(膝 − 足首) を 0〜1 に切り詰める。左右の悪い方を採る。

## 4. 衣類の範囲の決め方

### 4.1 脚の連鎖と座標

- 脚の連鎖: 股関節・膝・足首・（あれば）つま先の骨の点の列。
- 連鎖上の点: 連鎖の数 s について、区間 i = floor(s) を 0〜(点の数 − 2) に切り詰め、その区間を f = s − i で線形補間（最後の区間では 1 を超えて延長する）。その点での向きは「股関節側へ向かう」区間の向き。
- ある点の連鎖の数: 各区間に射影して最も近い区間を選び、区間番号＋区間内の割合。最初の区間で股関節より上に出た場合は負の値を許す。同時に連鎖までの距離も返す。

### 4.2 切る平面

平面は「点・法線・どちら側を残すか・どの脚に効くか（両方／左／右）」を持ち、さらに「ある点より上には効かない」「ある点から一定距離の外には効かない」という制限を付けられます。制限の外では、その平面からの符号付き距離を非常に大きな正の値とみなします（＝切らない、覆う距離にも効かない）。

| 種類 | 平面 | 種（残す部分を選ぶ点） |
|---|---|---|
| タイツ | ウエスト: 腰の中心 + 上 × (胸の高さ × ウエストの高さ)、法線 上、下を残す（両脚） | 左右の膝 |
| スパッツ | ウエスト（同上）＋各脚で裾: 連鎖の数 = 裾の位置 の点、法線 股関節側、股関節側を残す | 各脚の連鎖の数 = 裾の位置 × 0.5 |
| サイハイ・ニーハイ | 各脚で上端: 連鎖の数 = 上端 の点、法線 股関節側、足側を残す（ニーハイは上端の値だけが違う） | 各脚の (上端 + 2) ÷ 2 |
| 親指サック | 第 4.5 節の滑らかな形 | 親指の先端 |
| ガーター・レッグラップ | 第 4.6 節 | 帯の中心・巻き始めの点 |
| 手袋・アームカバー | 第 9.1 節 | 第 9.1 節 |

胸の高さ = (胸の目印 − 腰の中心)・上（胸が無ければ Spine）。

### 4.3 切り出し

1. 溶接した体を Blender のメッシュにし、各頂点に元の番号を記録する。
2. ガーター・レッグラップでは、上に着ている肌に密着した服（上の衣装の天井が 8 mm 以内）で覆われる面を先に消す（服の下に収めようとすると突き抜け、覆われる所は見えないため）。レッグラップでは巻く範囲の長い辺を先に分ける（第 4.6 節）。
3. 平面ごとに、効く面（制限の内側で、その脚の側にある面の中心）だけを平面で切り、効く面のうち中心が残さない側にある面を消す。孤立した頂点を消す。
4. 連結成分の選び方:
   - 脚の衣類: 各種の最も近い頂点を含む成分と、「頂点の脚の重みの平均が 0.5 以上の成分」を残す。
   - 腕の衣類: 種の成分だけ（腕の位置の無限平面で脚の一部が通り抜けるのを防ぐため）。
   - ガーター・レッグラップ: 切り方が正確なので、左右の脚にまたがる塊のほかは全て残す（縁を細かくした頂点は体の頂点番号を持たず、脚の塊と判定できないため）。
   - 脚・腕の衣類では、種で残した成分から全頂点が 8 mm 以内にある成分（指から離れた島になっている爪、ばんそうこうなど）は布にせず「島」として覚える。島の各点について、最も近い布の面の頂点に「面の法線方向の高さ」を記録し、その上の布を肌から少なくともその高さだけ離す（第 5.3 節の持ち上げと床の両方）。
   - 面が残らなければ失敗。
5. 体の切り口（肌が途中までしか無い体）: 範囲の開いた縁のうち、頂点の半分以上がどの平面からも 0.3 mm より遠く、長さが股関節の間の距離以上（腕では半分以上）の輪（脚・腕を一周する体の切り口）ごとに、縁に接する面の中心の平均が縁より下なら「縁の一番低い点 − 上 × 3 mm」に法線 上 の上端の平面（下を残す）を、上なら「一番高い点 + 上 × 3 mm」に下端の平面（上を残す）を足し（腕では上の代わりに、縁の中心に近い腕の区間の向き）、それで切って連結成分を選び直す。面が半分未満に減るなら切りそろえない（脚の形が人と違う体で何も残らないのを防ぐ）。足した平面は以後ほかの平面と同じに扱う（上端の帯もそこに付く）。体の切り口が斜めだと衣装の端も斜めになり、角が尖るため。
6. 覆う距離: 範囲に残った各頂点について、効く平面への符号付き距離（m）の最小値。フェイクサイハイで肌の写しを使わない場合は、境目（第 6.1 節）より下にある距離も候補に入れる（＝境目より上のストッキング部は「覆っていない」扱い）。範囲外の頂点は −1。これを元の頂点番号ごとに展開した物が、肌の削除などに使う「覆う距離」。
7. この範囲を布の素材として写しておく。別に、範囲の穴をすべて塞いだ閉じた物を作り、包絡面の材料とする。

### 4.4 滑らかな形で切る

平面に制限（球の中など）を付けて切ると、制限の境目で三角形の形のまま段になります。親指サック・レッグラップのらせん・手袋の親指の穴や絵描き用の切り口は、およその符号付き距離 f（正なら残す）で表し、f の符号が変わる辺を f = 0 の所（二分法 30 回）で分け、分けた点どうしを面の中でつないでから、頂点の f の平均が負の面を消します。範囲の穴を塞ぐときの「縁の上にあるか」は、平面では平面からの距離、滑らかな形では |f| で判定します。

### 4.5 親指サックの切り方

- 足の指の塊: 足の指ごとに骨を持つ体では骨のウェイトの番号、無い体では形で分けた塊（第 5.5 節 6）。足の付け根の平面（前への到達 × 0.55）より前・足首より下で、足の内側への座標の平均が最も大きい塊を親指とする。形で分けるときは、最も大きい塊の 5% より小さい塊（爪などの離れた部品）を数えない。
- 足ごとに滑らかな形（第 4.4 節）で切る: 残すのは「付け根より前」と「ほかの指の点より親指の点に近い（2 つの距離の差の半分）」の丸めた積（丸めの半径は到達 × 4%）。付け根は親指の塊の最も後ろの点だが、到達 × 0.6〜0.7 に収める（形で分けた塊は指が分かれる所より先だけで、骨のウェイトの塊は付け根の奥まで届く）。
- 塊が 2 つ以上に分かれない足は、指先（到達 × 0.8 より前）の内側への座標の幅の内側 35% と、到達 × 0.7 より前を残す。どちらも足首より下だけを残し、作れない足はその側をすべて切る。
- 縁の浮かせ（第 5.3 節 4）はしない。指先の張り（第 5.5 節）は、口の中心から先端までの前半分だけ。
- 肌との隙間は 0.3 mm 以下、指の間を埋めない（埋める幅 0 を送る）。

### 4.6 ガーター・レッグラップの切り方

- ガーター: 脚ごとに、脚の連鎖の数 = 帯の位置 を中心に、幅（mm。その区間の骨の長さで連鎖の長さに直す）の輪を残す（上の平面の足首側と下の平面の股関節側）。
- レッグラップ: 脚ごとに、巻き始めと巻き終わりの間（両端は脚に直交する平面）で、脚の座標 (s, u)（第 6.3 節）から、らせん u = ±回数 × (s − 始め)／(終わり − 始め) の中心線までの距離が幅の半分以内の所を滑らかな形（第 4.4 節）で残す。距離は、脚の周りのずれ（回転数）を点から脚の軸までの半径の弧の長さにし、らせんの傾きで縮めて測る。らせんの回転の進みは脚の連鎖に沿った脚の半径（40 区間の中央値）で決め、どこでも同じ傾きで巻く（太い所はゆっくり回る。等間隔だと太ももでリボンが寝て交差が潰れる）。交差させるときは逆向きのらせんも残す（同じ面から切るので交差する所は 1 枚）。両端には脚を水平に 1 周するリボンの幅の輪も残し、らせんは両端の輪の中心線の間だけにする。切る前に、巻く範囲（両端から連鎖で 0.1 の余裕）でリボンの縁の近くを通る辺のうち、リボンの幅の 90% より長い物を 3 回まで二分する（大きな三角形の頂点の間をリボンがすり抜けて消えない）。
- 付け根の近く: 股の底（体の中心線から股関節の間隔の 5% 以内で、股関節より下・膝より上の、法線が真下から 45° 以内の点のうち最も高い物）を求め、帯の上の縁（ガーターは中心 − 幅の半分、レッグラップは股関節側の端）の脚に直交する平面が股の底より 3 mm 以上下を通る最小の連鎖の数（0.01 刻み、両脚で大きい方）まで位置を下げる（股をまたいで左右の脚がつながらない）。
- 共通: 縁の浮かせと下着の上の余裕はしない。肌との隙間は 0.3 mm 以下。部位分けはせず全体を 1 つの部位にする（ゴムの帯の部位が縞のように交互に出るため）。

## 5. 布の形の作り方

### 5.1 基本の考え方

布は「覆う範囲の肌の面を、肌の法線に沿って外へ押し出した物」です。各頂点は元の肌の一点を覚えていて、Unity ではその点のウェイトとシェイプキーを使います。押し出しの量は「隙間＋厚み（以下、基本の浮き）」に、関節・裾・下の衣装の分を足した物です。単純に押し出すと崩れる所（へそ・細い溝・お尻の谷・足の指の間）は、SDF（符号付き距離場）で作った滑らかな包絡面を手がかりに直します。

### 5.2 包絡面（SDF）

Blender のジオメトリノードで次の面を作ります。

```
面 = メッシュ化( ラプラシアン平滑化 3 回 ( 距離場( 閉じた範囲 ) を 浮き だけ外へずらす ) )
閉じ処理(X) = 距離場( メッシュ化( 距離場(X) を r 外へ ) )   （閾値 浮き − r で面にする = 形態学的クロージングと浮きのずらしを 1 つの閾値にまとめる）
```

距離場の帯の幅は max(3, (r + 浮き)/格子 + 3) 格子。

| 面 | 材料 | 格子 | 閉じ処理 |
|---|---|---|---|
| 全体の包絡面 | 閉じた範囲 | 粗い格子 = max(細かい格子, 1.6 mm) | なし |
| つま先の面 | 閉じた足（下記） | 細かい格子 = max(計算の細かさ, (隙間 + 厚み) × 0.4) | r = 指の間を埋める幅 + 厚み |
| お尻の橋渡し面 | お尻の部分（第 5.4 節） | max(3 mm, 計算の細かさ) | r = 40 mm |

- 閉じた足: 体を「足首の高さ（左右の高い方）+ (膝の高さ（低い方）− 足首) × 0.2」の水平面で切って下を残し、切り口を塞いだ物。つま先の面を作る条件は「スパッツ・腕でない」「指の間を埋める幅 > 0（5 本指・親指サック・ガーター・レッグラップでは 0 を送る）」の両方。
- 足袋型: 足の指の塊が 2 つ以上に分かれる足だけ、閉じた足を作る前に、足先の体の点のうち「付け根の平面より前・足首より下で、最も近い指の点が親指以外の物」を、付け根の平面の上の親指と人差し指の中ほどを通る上向きの軸の周りに外側へ 25° × 割合だけ回す（割合は付け根の平面から親指の塊の最も後ろ（到達 × 0.7〜0.85 に収める）までで 0 から 1 へなめらかに）。開いた形で面を作ってから、面の頂点を元の向きへ戻す（開く側かは開いた後の指の点で見分ける。割合は戻した位置で決まるので 4 回の反復で求める）。親指を内側へ開くと、足を揃えた体で両足の親指が近づき、閉じ処理でつながるため。
- 全体の包絡面は粗い格子で作る（全体を細かく作ると時間の大半を占めるため）。細かい格子はつま先だけ。

### 5.3 肌から浮かせる

まず範囲の穴のうち、縁の全頂点がどれかの平面上（0.05 mm 以内）にある物（裾）以外を塞ぎます。下の衣装の通常の厚み = 下の衣装の高さが正の頂点の高さの中央値（無ければ 0）。

「内側に収める」（不透明、または利用者が選んだ時）なら下の衣装の高さに上限なし、そうでなければ上限 = max(4 mm, 通常の厚み × 2)。

範囲の各頂点 v について:

1. v を体に結び付け、その肌の点 B、法線 N を得る。
2. 関節量 j = clamp(関節の混ざりの補間値 × 2, 0, 1)。
3. 下の衣装の高さ w = 補間値（上限で切る）。お尻の谷の処理（第 5.4 節）で w を調整する。w > 0 なら w += 2.5 mm × clamp(w／1 mm, 0, 1)（下の衣装は自分のウェイトで動くので余裕を足す）。
4. 裾の浮き: 効く平面への最小距離 d で f = clamp(1 − d／25 mm, 0, 1)、裾の浮き = 2.5 mm × f²(3 − 2f)。裾は体の三角形の途中を切るのでウェイトが補間になり、腰が動くと肌から離れる。実物のゴムのように裾の近くだけ浮かせる。親指サック・ガーター・レッグラップ、および腕の衣類の滑らかな形（指の付け根・親指の穴）の縁では行わない（手は小さく、25 mm の帯で口が釣り鐘のように開く）。
5. 浮き量 = 基本の浮き + w + max(関節の余裕 × j, 裾の浮き)。
6. 狭い溝の制限（第 5.5 節）で浮き量を抑える。
7. 上に着ている物の制限: 結び付けた三角形の角（重心座標 > 1e-4）の「上の衣装の高さ」の最小値を天井とし、上限 = max(0.3 mm, 天井 − 0.4 mm)。浮き量をこれ以下に抑え、記録する（後で何度か押し戻すため）。
8. 位置 Q = B + N × 浮き量。
9. お尻の谷にあれば、橋渡し面へ寄せる（第 5.4 節）。
10. 包絡面との照合（橋渡しの重みが 0.5 を超える頂点は行わない）: 包絡面上の最近点との深さ（内側を正）が 6 mm を超えれば「内部の頂点」として印を付ける。0.2 mm を超え 3 mm 以下なら包絡面上の点へ移す（へそや小さなしわを持ち上げる）。それより深いしわは追う（遠くへ動かすと関節が回った時に肌から離れるため）。
11. 頂点に「元の肌の点 B」「肌に正確に沿う」印を記録する。また後段で使う「枠」（肌の点・法線・最低の高さ）を記録する。最低の高さ = min(浮き量, (内側に収めるなら 基本の浮き + w、でなければ 基本の浮き) + 裾の浮き)。島（第 4.3 節）の下では「基本の浮き + 島の高さ」を下回らない。橋渡しされた頂点の枠は、橋渡し面の最近点を基本の浮きだけ内へ戻した点・その面の法線・基本の浮き + 橋の上の余裕。縁の浮かせを下限に含めないと、しわ取りで縁が鋸の歯になる。

続けて:

- 橋渡しされた頂点（重み > 0.5）を 8 回、隣の平均位置を橋渡し面へ投影し、法線方向に各自の余裕だけ浮かせた点へ動かす（谷の両壁が順序を乱して着地し面が折れるのを直す）。
- 溝埋め（外へだけの平滑化）: 10 回、頂点の隣の平均が法線方向で外にあれば、その差の半分だけ外へ。最後に元の位置からの外向きの移動を 0〜4 mm に切り詰め、元の法線方向へ適用する。橋渡しされた頂点は元に戻す。
- 指先を張る（第 5.5 節 6）。
- 上の衣装の制限と狭い溝の制限を改めて適用し、超えた分を法線に沿って押し戻す（橋渡しされた頂点と、狭い溝の制限では張った指先も除く）。
- 全頂点が内部の頂点である面を消し、孤立頂点を消す。

### 5.4 お尻の谷の橋渡し（タイツ・スパッツ）

布はお尻の割れ目に沿って入り込まず、上を渡ります。

お尻の領域（脚の長さ L = 左の股関節から足首までの距離、腰の幅 = 股関節間の距離）:

- 前 = 左足の前（足首→つま先、水平化）。
- 半幅 = 腰の幅 × 0.35。
- 股の高さ: 中心線近く（|横| < 0.02L、|前| < 0.2L、−0.4L < 高さ < 0）で法線が下向き（法線・上 < −0.5）の頂点の最低の高さ（無ければ −0.1L）。下端 = 股 − 0.01L、上端 = 0.25L、ぼかし幅 = 0.04L。
- 重み = smoothstep(a)、a = clamp((1 − |横|／半幅)／0.4) × clamp((高さ − 下端)／ぼかし) × clamp((上端 − 高さ)／ぼかし) × clamp(−前方向の位置／ぼかし)。後ろ側だけ（前の股は追う方が良い）。
- 高さ方向の薄切り（0.004L ごと）に、領域内の三角形が触れる各薄切りの「最も後ろの位置」を記録する（後ろの輪郭）。
- お尻の部分の物体: 体を上端 + ぼかし・下端 − ぼかし・左右 ±(半幅 + ぼかし) の 4 平面で切り、穴を塞いだ物。これから橋渡し面（第 5.2 節）を作る。

各頂点の谷の判定:

1. 重み > 0 なら、橋渡し面の最近点 H と法線 M を取る。谷の深さ = −(B − H)・M − 基本の浮き。
2. B から H への道が開いているか: B から H 方向へ 1 mm 進んだ所から H まで光線を飛ばし、体に当たらないこと（太ももの脇のしわから、太ももの向こうの橋に寄るのを防ぐ）。
3. 道が下向き（股から下へ）なら弱める: 重み × clamp((道の向き・上 + 0.8)／0.5)。
4. 深さ > 0.2 mm、道が開いている、重み > 0 なら「橋渡しする」。下の衣装の高さ w を、w + (min(max(通常の厚み + 1 mm, w − 谷の深さ), w) − w) × 重み に変える（谷を横切って測った高さを、橋の上での残りの高さにする）。

橋渡しする頂点は、余裕 = 浮き量 − 基本の浮き（下の衣装があれば、肌の法線が下の衣装に当たる点の橋からの高さ〔通常の厚み × 1.5 まで〕+ 2.5 mm との大きい方）とし、Q を (H + M × 余裕) へ重みの割合だけ寄せます。

お尻の輪郭の保持（仕上げで 2 回）: 各頂点の元の肌の点の高さの薄切りに後ろの輪郭があり、お尻の重みがしきい値（1 回目 0、2 回目 0.5）を超える頂点で、前方向の位置が「輪郭 − (基本の浮き + 通常の厚み)」より後ろに出ていれば、前へ押し戻す。ただし押し戻すと枠の最低の高さを下回る場合は動かさない（谷の底が側面から見てひれのように出るのを防ぐ）。

### 5.5 狭い溝の制限と指先の張り

狭い溝の制限:

- 向かいの肌: B + N × 0.3 mm から法線方向へ「浮き量 × 2」の距離まで光線を飛ばし、体に当たれば、上限 = (当たった距離 + 0.3 mm)／2（向かい合う壁の布どうしが交差して暗いしわになるのを防ぐ）。
- 体の中心線を越えない: 横方向の位置 x、法線の「中心へ向かう」成分 c = (N・横) × (−x の符号)。|x| > 0.5 mm、c > 0.05、股関節より下 なら、上限 = min(上限, |x|／c × 0.9)（太ももの間で反対側へ出ない）。
- 上限が有限なら、上限 = max(0.1 mm, 上限, 下着の下限, 島の下限)。下着の下限は、内側に収める かつ w > 0 なら 基本の浮き + w。ただし股（股関節より下で、体の中心線から 40 mm 以内）で下着の下限が上限より大きい所では 0（下着はくぼみをまたいでいるので、向かい合う壁をそれぞれ下着の高さまで持ち上げると左右の衣装が交差して折れ目になる）。浮き量をこれ以下に抑え、記録する。

指先を張る（指を包む手袋〔5 本指・オペラ・絵描き用〕の指先と、足の指ごとに骨を持つ体の 5 本指の足の指。切り口の縁の頂点は動かさない）: 伸びた布は膜のように、爪の付け根や両脇の溝・長い爪の先の下に入り込まず、出っ張りの間に張ります。

1. 区間: 手は、中指の付け根から先の関節までの長さ L で、付け根から 0.55L より先。指の番号は、指をまたぐ向き（人差し指 − 中指の付け根の、中指の向きに直交する成分）の位置を指の間隔で割って丸めた物。親指は中間の関節より先で、親指の軸から親指の区間長の 1.3 倍以内（長さの 3 倍まで）の、ほかの指でない所。
2. 同じ番号で辺がつながる塊（指 1 本）ごとに、頂点の凸包を作る（近くの爪の島の点を基本の浮きだけ 6 方向に広げた物も入れる）。各頂点を、法線方向の光線が凸包に当たる所まで持ち上げる（15 mm まで）。
3. 10 回、隣の平均と半分ずつ混ぜて角を丸める（元の体の点から法線方向に基本の浮きより内へは入れない）。最後に、凸包の面より基本の浮き／2 を超えて内に入った頂点を凸包の面へ戻す。
4. 爪の島の各点が、最も近い布の面の内側に基本の浮き × 0.75 以上入るまで、その面の頂点を面の法線の向きへ押し出す（4 回まで）。
5. 足の指: Unity が渡した指の番号（第 3.3 節）で、布の各頂点の元の体の点で重心の最も大きい角の番号ごとに張る（持ち上げは 6 mm まで）。上に履いた靴下などの天井はこの後も効く。
6. 足の指の骨の無い体の 5 本指: 足ごとに、足首から前への到達の割合 r（0.6 から 0.95 まで 0.025 刻み）より前で足首より下の布の頂点を辺のつながりで塊（8 頂点以上）に分け、塊がちょうど 5 つになる最小の r の塊を指ごとに張る（5 つにならない足は張らない）。この「形で分けた塊」は親指サック・足袋型の親指の判定にも使う。
7. 張った頂点は、後のしわくちゃのならし・こぶの平坦化・狭い溝の制限から外す（張った面は爪の下の肌と向きが違い、元へ戻されるため）。出力の法線も、張った指先では体の法線でなく布自身の法線を使う。

### 5.6 つま先（まとめ・足袋型）

足の枠（左右それぞれ）: 足首より低い頂点（10 点未満なら無し）について、前 = 足首→つま先の骨（無ければ体の前）を水平化し、低い頂点の平均が後ろなら向きを逆にする。前への到達 = 前方向の射影の最大、後ろへの到達 = 最小の符号反転。

つま先の区域（範囲がその足を覆っていれば）:

- 平面: 足首 + 前 × 前への到達 × 0.55（指が分かれ始める所）、法線 前、前側が区域。
- 上限の高さ: その足の、平面より前にある頂点の足首からの高さを並べ、隣り合う差が 前への到達 × 0.15 を超える最初の所（無ければ最後）の高さ + 前への到達 × 0.5。差があれば、次の塊の高さ − 差 × 0.2 で抑える。0 以上。
- 区域 = その足の側・上限の高さ以下・平面より前。

差し替え:

1. 目標三角形数 = 区域内の布の三角形数 × 足先のポリゴン密度（最低 200）。
2. 布を区域の平面で切り、区域の外だけを残す。
3. つま先の面から区域の周り（平面の少し後ろ: 平面と足首の距離の 0.2 倍の余裕）を取り出し、平面で切って区域の中だけを残す。崩し簡略化（辺の縮約）で目標数へ減らす。
4. これを布に加える。加えた頂点は「肌に正確に沿わない」印、元の肌の点はその頂点自身の位置。
5. 足ごとに、平面上（0.05 mm 以内）にある縁の閉じた輪を、肌に沿う側と面の側で 1 本ずつ探す（2 端の間が辺の最大長の 3 倍以内なら 1 か所の切れ目を閉じる）。見つかれば、2 本の輪を平面上の角度順に並べ、角度の小さい方から進めて三角形でつなぐ（縫い合わせ）。見つからなければ警告を出してつながない。
6. 面の向きを揃え直す。継ぎ目の段差をならす: 平面からの距離が「平面と足首の距離 × 0.12」以内で区域の近く、縁でない頂点を、隣の平均との中点へ 6 回。
7. つま先を張る: 区域の頂点（縁を除く）を、足ごとの凸包の最も近い面まで持ち上げる（6 mm まで。法線の向きだと、指の間の溝の頂点は隣の指の方へ横にずれるだけで溝が埋まらない）。続けて第 5.5 節と同じく角を丸め、凸包へ戻す。実物のストッキングのように、指をまとめて包む 1 つの面にする。足袋型では凸包を足ごとに親指とほかの 4 本で分ける。出力の法線は、区域では布自身の法線を使う。その後、指から離れた島の爪を覆う。
8. 上の衣装（靴など）の制限: 差し替えた頂点を最寄りの肌に結び付け、第 5.3 節の上限を超えた分を法線に沿って押し戻す。押し戻しがあれば、縁でない頂点の中点平滑化と押し戻しを 5 回繰り返す（指先の周りで法線が急に回り、皺になるため）。

5 本指（埋める幅 0）・スパッツ・腕の衣類・親指サック・ガーター・レッグラップでは差し替えず、体の指の形がそのまま残ります。足袋型で指の塊が分かれない足は「まとめ」と同じです。

### 5.7 崩れの修正

いずれも「形で見つけ、どこにあっても直す」方針です。

- しわくちゃの面の緩和: 面の法線と、その角の枠の法線の和の向きとの内積が 0.5 未満（60 度超）の面を探す。最大 24 回、その頂点と、回ごとに 1 輪ずつ広げた周りの頂点を、肌の法線上の「隣の高さの平均」の位置へ移す。高さは枠の最低の高さ（と 0.5 mm）を下回らない。後半 12 回は高さを最低の高さへ向けて 0.8 倍ずつ縮める。張った指先は対象外。上の衣装・狭い溝の押し戻しを再び行う。
- 高品質の細分化（第 5.8 節）。
- こぶの平坦化: 6 回まで、肌からの高さが隣の高さの中央値より 3 mm を超えて高い頂点（隣 3 点以上）を、max(中央値 + 0.75 mm, 最低の高さ) へ下げる。
- お尻の輪郭の保持（1 回目、第 5.4 節）。
- たるみ（第 5.9 節）。
- 小さな穴: 縁の辺で、両端の元の肌の点がどの平面からも 0.3 mm より遠い物（裾でない物）が 1〜24 本なら塞ぐ。残った物は品質の報告の「穴」。
- 部位分け（第 6.1 節）。
- 下の衣装の上に乗せる（第 8.4 節。ガーター・レッグラップでは行わない）。
- 折れ目の平滑化: 床（枠の点・法線・最低の高さ。下の衣装の上に乗せた頂点は必要な高さの高い方）を使う。両端に床がある辺で、面の折れが 60 度を超え、かつ肌の法線の角度より 35 度以上大きい物を「折れ目」とする。最大 10 回、折れ目の頂点と隣を、隣の平均との中点へ移し、床より下なら持ち上げる。元の位置から肌の点への距離が「最初の距離 + 2 mm」を超えたら元に戻す。元の肌の点の法線の線から 2 mm 以上離れた頂点と縁の頂点は動かさない。
- お尻の輪郭の保持（2 回目、重みのしきい値 0.5）。
- 体の三角形の中を覆う（第 5.11 節）。
- 小物の下の層への載せ（第 5.12 節）、リボンの結び目（第 5.13 節）。

### 5.8 高品質の細分化

予算 = 最大三角形数（2 層式は裏地の分を見込んで半分）。余地 = 予算 × 0.85 − 現在の三角形数 − 縁の辺の数 × 4（縁の厚みで増える分）。辺を長い順に「余地 ÷ 2」本まで選び（各 1 回まで）、1 か所ずつ分割して角を丸める（平滑 0.3）。5 角形以上は三角形にする。

新しい頂点: 両隣が肌に沿う頂点なら、両隣の元の肌の点の平均を肌に結び付け直して元の肌の点とし、肌から基本の浮き未満なら法線方向へ持ち上げる。そうでなければ、その頂点自身を元の肌の点とする。

分割で要素が入れ替わるので、枠を作り直し（肌に沿う頂点: 肌の点・法線・内側に収めるなら 基本の浮き + w、でなければ 基本の浮き。島の下ではその高さも）、張った指先を枠から外し、しわくちゃの緩和をもう一度行います。

### 5.9 たるみ（足首と膝裏のしわ）

量 0〜1 に対し振幅 = 1 mm × 量。肌に沿う頂点の元の肌の点から脚の座標 (s, u) を求め（第 6.3 節）、

- 足首: s が 1.75〜2.0（両端 0.06 でぼかす）。
- 膝裏: s が 0.9〜1.1（両端 0.05）、かつ脚の後ろ（|u − 0.5| < 0.2、端 0.08 でぼかす）。
- 重み w = 2 つの大きい方。山 = 0.5 + 0.5 sin(2π s／0.035 + 0.6 sin(2π × 3u))。
- 枠の法線方向へ 振幅 × w × 山 だけ外へ動かす（外へだけなので肌は出てこない）。

### 5.10 厚み

布の面を物体にし、ソリッド化（厚み = 布の厚み、内側へ、均一化なし〔鋭い角で尖るため〕、高品質な法線、縁あり・縁だけ）を付けます。内側の面は体が埋めて見えないので、厚みは裾の縁にだけ作ります。面は滑らかな陰影にします。

### 5.11 体の三角形の中を覆う

脚の衣類で、範囲の縁から 2 mm より内の体の三角形のうち、足首より上の物について、三角形の中の 9 点（重心、辺の中点、重心と各頂点・各辺の中点の中ほど）のうち、布の面の外へ突き抜けた点を、面の内側 基本の浮き × 0.2 まで入れる。点に最も近い布の面が、その点の近く（面の頂点の元の体の点の平均が、三角形の最長辺の 2 倍以内）の肌から作った面なら、足りない分だけ面の頂点を面の法線の向きへ押し出し、押し出す量を隣の頂点へ半分ずつ 2 段まで分ける（4 回まで）。布の頂点は肌の外でも、橋渡しなどで頂点が横にずれると、肌の三角形の真ん中が布の面を突き抜けるため。足先と腕の衣類では行わない（指の間では布どうしが近く、どの面を押しても隣の指の布とぶつかる）。

### 5.12 小物を下の層に載せる（ガーター・レッグラップ）

下の層（前に作ったタイツ・靴下、アバター自身の脚の服）があれば、仕上げの後に各頂点から法線の向きに 15 mm まで光線を飛ばし、最後に当たった下の層の面の外 基本の浮き まで持ち上げます（下の層が何枚も重なっても一番外に載る。向かいの脚の服には届かない）。持ち上げる量は隣と 3 回平均し、各頂点で自分に要る量を下回らない（服の細かな凹凸を頂点ごとに拾うと帯が裂けて見え、隣の最大で広げると全体が数 mm 浮く）。体の中心線の手前で止める（脚がくっついた体で内ももが向かいの脚の側へ出ない）。下の層の面からの作り直し（第 8.4 節）はしない（下の層のタイツは体のウェイトで動き、その面をなぞると左右の膝の間などで左右の脚にまたがる）。

### 5.13 リボンの結び目（ガーター）

リボンがオンのガーターでは、仕上げの最後に、脚ごとの帯の外に結び目を閉じた立体として足します。帯の中心の脚の軸から、前から外側へ 35° 回した向きに帯の外面を探し、そこを原点に、脚の周り・軸に沿った向き・外面からの高さの平らな座標で、リボンの断面（幅 = 帯の幅 × 0.32、厚み 0.6 mm。両端を半径 = 厚みの半分の半円に丸めた平たい形）を道筋に沿って掃きます。

- 2 つの羽根: 結び目から外へ出て先で折り返し帯の側へ戻る、ふくらんだしずく形の道筋（長さ = 帯の幅 × 0.95、ふくらみ = 帯の幅 × 0.32 × 先への割合^0.7。付け根では 0 で横から穴が見えない）。リボンの幅（帯の幅 × 0.75）は脚の軸の向き。幅は結び目で 45%、中ほどで最大、先で 77%。左右で少し上下に開き、帯から 12° 起こす。
- 2 本の垂れ: 下へ帯の幅の 1.7 倍と 1.55 倍、外へ少し開き緩い S 字。幅はリボンの 62% から先へ 15% 広がる。
- 結び目: くびれた羽根の付け根を縦に巻く短く太い輪。幅はリボンの 32%、厚み 1.4 倍。
- 帯の外面と結び目の間は 0.4 mm。部位は帯、陰影は布自身の法線。垂れの頂点には、垂れの番号と根元からの割合を付けて出力する（`output.json` の `swing`。第 7.8 節）。

## 6. 部位分けと見た目

### 6.1 部位分け（Blender）

面ごとに部位の番号を付けます。境界は平面で切るので、編み目の境のようにまっすぐな線になります。大きさは脚の長さ L に比例します。

| 番号 | 部位 | 決め方 |
|---|---|---|
| 0 | 脚（既定） | 下のどれにも当たらない |
| 1 | パンティ部 | タイツ: ランガードの位置より股関節側 |
| 2 | 帯 | 上端の平面（残す側が「下」の平面: ウエスト・ソックスや手袋などの上端。体の切り口で足した上端も）から 0.035L 以内。ランガード: 連鎖の数 0.2 の位置から足側へ 0.03L の輪 |
| 3 | 補強 | 足首より下で、つま先の平面のどれかより前、またはかかとの平面の全てより後ろ |
| 4 | 上部 | フェイクサイハイ: 境目より股関節側（脚の部位のままの所） |
| 5 | ソックスの帯 | フェイクサイハイ: 境目から足側へ 0.035L 以内（補強を除く） |
| 6 | 中心の縫い目 | タイツ: 中心線から ±0.003L、股 − 0.05L より上、前（股より前）／後ろ |
| 7 | ひしマチ | タイツ: 股の下の菱形 |

優先順位: 補強 → ランガード帯／パンティ → 上端の帯 → フェイクの上部・ソックスの帯 → 縫い目・マチ（最優先で上書き）。

- 上端の帯は「ウエストバンド」がオンの時だけ。パンティ部・ランガードはそれぞれのオンオフに従う（ランガードがオフなら帯の幅 0）。ガーター・レッグラップは全体が「脚」の 1 部位。
- フェイクサイハイの境目: 各脚の連鎖の数 = 境目の高さ の点と股関節側の向き。境目の帯がオフならソックスの帯の幅は 0。
- 足（タイツ・サイハイ・ニーハイで、つま先かかかとの補強がオン）: 各足の枠を作り、足首の高さで足首の近く（0.25L 以内）を切る。つま先の点 = 足首 + 前 × 前への到達 × 0.70。
  - つま先・まっすぐ: その点を通り法線 前 の平面。
  - つま先・包む形: さらに、点 − 前 × 前への到達 × 0.12 ± 外側 × 前への到達 × 0.12 を通り、法線を前から外側へ 40 度回した平面 2 枚。
  - かかと・カップ: 足裏の高さ（足首からの最低）を sole（負）、後ろの端 = 足首 − 前 × 後ろへの到達。上の平面（足首 + 上 × sole × 0.35、法線 上）、前の平面（後ろの端 + 前 × 0.3 × (前への到達 + 後ろへの到達)、法線 前）、その角を面取りする平面（角 − (上+前 の単位) × (−sole × 0.3)、法線 上+前 の単位）。
  - かかと・Y ヒール: 足首 − 前 × 後ろへの到達 × 0.1 を通り、法線 = 単位(前 + 上 × 0.8) の 1 枚。
- 股（タイツで縫い目かマチがある時）: 股の点 = 布の頂点のうち中心線近く（|横| < 0.03L、|前| < 0.25L、股関節より下）の最低の点。前は体の前。
  - マチ: 半幅 a = 腰の幅 × 0.2 × 大きさ、前後の半長 b = a × 縦横比、中心 = 股の高さ・股の前後位置の中心線上。4 平面（中心 ± 横 × a を通り、法線 = 単位(横 × (±1／a) + 前 × (±1／b))）の全ての内側で、高さが 股 + 1.5a より低く、|横| < 腰の幅 × 0.6 の所。
  - 縫い目: 中心線 ±0.003L で切る。

### 6.2 伸びの透け具合（Blender）

布が伸びた所ほど光を通す、という考えで、頂点ごとに「透過の倍率」= 1／s（s は面積の伸び）を求めます。

脚（左右それぞれ、頂点の連鎖の数 t と連鎖までの距離 r）:

1. 太さの伸び: t が 0〜2 の頂点が 10 未満なら、その脚は 1 のまま。r の 10 パーセンタイルを基準 r0 とし、q = r／r0。ぼかし = clamp(t／0.15) × clamp((2 − t)／0.15)。s = 1 + 0.25 × max(q − 1, 0) × ぼかし（股関節・足首の近くと足は 0）。
2. 膝の前: s += 0.35 × exp(−((t − 1)／0.15)²) × clamp(法線・足の前)。
3. 隣の平均との中点を 4 回。s = 1 + 強さ × (s − 1)。倍率 = clamp(1／s, 0.3, 1)。

腕: 同様の太さの伸び（手首から先は太さの項なし）に、肘の後ろ（t = 1、幅 0.15、法線・(−体の前)）× 0.35 と、手の甲の指の付け根（t = 3、幅 0.12、法線・上、中指の目印がある時）× 0.3 を足します。

強さ（ジョブの値）: 見た目が透ける（またはフェイクサイハイ）で、かつ「不透明の引っ張り透け」でない時に、実際の強さ（第 6.4 節）。それ以外は 0（＝全て 1）。

### 6.3 脚の座標（Blender）

各頂点の元の肌の点について、

- s = 連鎖の数（第 4.1 節）。
- u = 脚の周りの角度（回転数）。その点の区間の軸に垂直な成分を取り、足の前（左右の足の枠の前の平均。無ければ体の前）を軸に垂直にした向きを 0 として、軸回りに測る。左右で鏡像になるよう、左脚は符号そのまま、右脚は符号を反転する。0〜1 に折り返し、右脚には 2 を足す（柄を片脚だけに入れられるように）。

面の角ごとの値: 1 つの面の角が全て同じ脚で、u の幅が 0.5 を超える（脚の前の 1→0 の継ぎ目をまたぐ）なら、u − (脚のずれ) < 0.5 の角に 1 を足して連続させます。

### 6.4 透けの物理（デニール）と設定から決まる判定

正面から見た覆い率（光を遮る割合）をデニールから線形補間します。

| デニール | 0 | 5 | 10 | 15 | 20 | 30 | 40 | 60 | 80 | 110 | 200 | 1000 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 覆い率 | 0 | 0.08 | 0.15 | 0.22 | 0.30 | 0.45 | 0.60 | 0.82 | 0.95 | 0.99 | 1 | 1 |

厚み（mm、推定値。200D 超は裏起毛の保温の目安）:

| デニール | 0 | 10 | 20 | 40 | 80 | 110 | 200 | 400 | 700 | 1000 |
|---|---|---|---|---|---|---|---|---|---|---|
| 厚み | 0.08 | 0.10 | 0.15 | 0.25 | 0.40 | 0.50 | 0.90 | 1.50 | 2.20 | 3.00 |

- 覆い率 0.95 以上を「不透明」とします。
- 見る角度による濃さ: 法線から θ の方向から見ると、透過 (1 − c) が (1 − c)^(1／cosθ) になる（cosθ の下限 0.02）。縁ほど濃く見える。
- 表示の区分: 15 未満 極薄、25 未満 薄手、50 未満 半透明、80 未満 ほぼ不透明、200 未満 不透明、それ以上 厚手。

設定から導く値:

| 値 | 定義 |
|---|---|
| 不透明か | 2 層式、または覆い率 ≥ 0.95 |
| 引っ張りで透ける | 不透明・2 層式でない・フェイクでない・引っ張り透け > 0・200D 未満 |
| 実際の強さ | 引っ張りで透けるなら 伸びの強さ × 引っ張り透け × clamp((200 − D)／140)、でなければ伸びの強さ |
| 見た目の覆い率 | 2 層式は見かけのデニールの覆い率、引っ張りで透けるなら 1、他は覆い率 |
| 見た目が透ける | 2 層式は見た目の覆い率 < 0.95、他は 不透明でない か 引っ張りで透ける |
| フェイクの上部が透ける | 上部のデニールの覆い率 < 0.95 |
| 姿勢の伸びを使う | 姿勢で変えるがオン・腕でない・(見た目が透ける か フェイクの上部が透ける)・実際の強さ > 0 |
| 肌の写しを使う | 肌の写しがオン・2 層式でない・(見た目が透ける か フェイクの上部が透ける) |
| 肌を消す | 「常に」、または「自動」で (不透明 か 肌の写しを使う) |
| 下の衣装を内側に収める | (不透明でフェイクでない) または 「内側に収める」を選択 |
| Blender に渡す隙間 | 親指サック・ガーター・レッグラップでは min(隙間, 0.3 mm)、他は隙間 |
| Blender に渡す埋める幅 | 5 本指・親指サック・ガーター・レッグラップでは 0 |

### 6.5 マテリアル

lilToon がある時（無ければ Unity 標準のシェーダーで、色 × 陰影の倍率だけ）。メッシュのサブメッシュは部位ごと（第 7.2 節）で、部位ごとに 1 つのマテリアルを作ります。

部位ごとの編み方（覆い率は 1 − (1 − c)^密度、色は 色 × 陰影）:

| 部位 | 密度 | 陰影 |
|---|---|---|
| パンティ部 | 1.6 | 0.97 |
| 帯・ソックスの帯 | 3 | 0.85 |
| 縫い目 | 3 | 0.75 |
| マチ | 2 | 0.82 |
| 補強（サンダル） | 1.3 | 0.97 |
| 補強（その他） | 2.2 | 0.9 |
| 脚・上部 | 1 | 1 |

部位の生地: フェイクサイハイの上部・パンティ部・帯・縫い目・マチは「上部の生地」（上部のデニールの透け・上部の色）、それ以外は本体の生地（見た目が透けるか・見た目の覆い率・色）。

- 不透明の生地: lilToon の不透明モードで、色を設定。
- 透ける生地: lilToon の透過モード。
  - 第 2 テクスチャに「視線角度の透け」の画像（128×128、中心からの半径 r の画素で cosθ = √(1 − r²)、アルファ = 第 6.4 節の角度の式。覆い率は部位の密度を掛けた物）を、MatCap の UV で読み、アルファを置き換える。色も同じ色。
  - 透明の切り捨てのしきい値を 0.001 にする（既定の 0.5 では薄い生地が消えるため）。
  - 伸びの透け: 実際の強さ > 0 で引っ張り透けでない時、アルファマスクに「ランプ」画像（256×4、UV0.x を元の値に戻す変換）を掛け算で使う。メッシュの UV0.x に倍率をランプ用に写した値が入っている。
  - 専用のカスタムシェーダー（`LegWeaver/Transparent`。詳細設計 S）が見つかれば差し替える。姿勢の伸びの強さ（`_LWDynamicStretch`）: 使わないなら 0、引っ張り透けなら実際の強さ、それ以外は 1。姿勢の伸びがオフでも、透ける生地はこのシェーダーを使う（深度の先行パスのため）。
- 裏面は描かない（カリング背面）。質感を適用（第 6.7 節）。
- 猫の飾りのフェイクサイハイの上部は、アルファマスクと姿勢の伸びを切る（耳が伸びで薄くならないように）。
- 2 層式: 先頭に不透明の裏地のマテリアル（色は肌の推定〔第 6.8 節〕または指定色）。裏地は描画の深さを少し奥へずらす（同じ深さの透ける表地が深度比較で負けないように）。
- 包む種類は「脚」の 1 部位。

### 6.6 姿勢の伸びのデータ（Unity）

装着後、姿勢で透けを変えるシェーダーを使うマテリアル（`_LWDynamicStretch` > 0）があれば、メッシュに次を書きます（脚だけ。腕は伸びが骨の継ぎ目にあり、この方法では捉えにくいため静的な伸びだけ）。

1. 接線: 各頂点に「アバターの上方向（メッシュ空間）」を、立ち姿勢でスキニングした長さが 1 になるよう縮めた物を入れる（w = 1）。関節が曲がると線形ブレンドスキニングで短くなるので、c = 1 − 長さ が曲がりの量になる。
2. 衣装の骨の写しを一時的に曲げる（股関節 70 度で膝が前へ、膝 100 度で足首が後ろへ、足首 30 度でつま先が下へ。軸はアバターの上×前）。各頂点の周りの面積（隣の三角形の外積の大きさの和）を立ち姿勢と比べ、k = clamp((面積比 − 1)／max(c, 0.05), −12, 12)（c < 0.01 や面積 0 は 0）。曲げは後で元に戻す。
3. k を隣と 3 回平均し（自身と隣の平均の中点）、UV の第 4 チャンネル（0 始まりで 3）の x に入れる。シェーダーは 1 + k × (1 − 接線の長さ) を伸びとして使う（詳細設計 S 2.3）。
4. スキニングの行列は「ルートボーンの位置と回転（拡大なし）」の空間で計算する（シェーダーが受け取る空間に合わせる）。

### 6.7 質感

「標準」は lilToon の既定のまま。それ以外は影（強さ 0.45、境 0.5、ぼかし 0.5。トゥーンは強さ 0.6、ぼかし 0.03）を付け、

| 質感 | 滑らかさ | 反射率 | トゥーンの鏡面 | リムライト（強さ・境・ぼかし） |
|---|---|---|---|---|
| マット | 0.25 | 0.02 | なし | なし |
| セミグロス | 0.55 | 0.04 | なし | 0.25・0.5・0.6 |
| 光沢 | 0.75 | 0.08 | なし | 0.4・0.5・0.6 |
| サテン | 0.9 | 0.16 | なし | 0.6・0.5・0.6 |
| トゥーン | 0.7 | 0.06 | あり | 0.35・0.6・0.05 |
| 綿（手袋のみ） | 反射なし | — | — | なし |

金属感は 0、鏡面を適用。手袋以外で綿が選ばれていたらマットに直します。

### 6.8 肌の色の推定

- 裏地の色: ボディのサブメッシュのうち、脚の重み 0.9 以上の頂点が最も多い物のマテリアルについて、主テクスチャを 128×128 に描き写して読み、その頂点の UV（0〜1 に折り返す）で双線形に取った色の平均 × マテリアルの色。テクスチャが無ければマテリアルの色、マテリアルが無ければ指定色。アルファは 1。
- 脚の色の違い（警告用）: 骨を「脚（大腿骨の子孫）」「胴と腕（Spine・Chest・UpperChest と上腕の子孫）」に分け、ウェイト 0.9 以上で頂点を分類し、各頂点の色（主テクスチャ × 色）を CIE L\*a\*b\*（D65）にし、2 群の各成分の中央値の差の長さを返す。

### 6.9 柄（第 3 テクスチャ）

柄・グラデーション・伝線・ソックスの口ゴムの飾り・フェイクの飾りがある部位のマテリアルに、2048×2048 の画像を lilToon の第 3 テクスチャとして UV1 で貼ります。付ける条件: ソックスで口ゴムが無地でなく部位が帯／グラデーション／伝線 1 本以上／バックシームで部位が補強以外／ドット・猫で部位が脚／フェイクサイハイで境目の飾りがあり部位が上部かソックスの帯／猫の飾りで部位が脚。透ける生地ではアルファを「加算」（柄の所は濃く編んだ＝透けにくい）、不透明では色だけ。横方向は繰り返し、縦は端で止める。

UV1 = (u／4, (s + 1.5)／5)。画像の横は左脚 u ∈ [0,2)、右脚 [2,4)、縦は s ∈ [−1.5, 3.5]。

ぼかしの関数: Smooth(d, w) = smoothstep(0, 1, clamp(d／w + 0.5))。網目 Net(s, u, n, a): x = (u·n の小数部) − 0.5、y = (s/a の小数部) − 0.5、Smooth(0.3 − √(x² + y²), 0.05)。

画素ごとに:

1. 基本色 = 生地の色（× 陰影）を、グラデーションがあれば smoothstep(範囲内の割合) でグラデーションの色へ。
2. 柄の量 p（0〜1、下記）で、色を柄の色（上部の部位では本体の色＝ソックスが伸び上がった色）へ寄せる。
3. ソックスの口ゴム（帯の部位）: レースなら網目 Net(s, u, 56, 0.014) × 0.75 の割合で肌の色へ（穴から肌が見える）。滑り止めなら波 s／0.01 + 0.25 sin(2π × 14u) の整数からのずれで 0.25 × Smooth(0.18 − ずれ, 0.05) の割合で白へ。
4. 猫の飾り: 脚・ソックスの帯に、境目の下に猫の顔（目・鼻・ひげ）を上部の色で描く。
5. 伝線を肌の色へ 0.7 × 寄せる。
6. アルファ = 透けるなら p × 設定の「柄の濃さ」（猫の耳は 1）、不透明なら 1。

柄の量 p（入れる脚に該当する時）。足の付近は Smooth(1.9 − s, 0.06) でぼかす。

| 柄 | 対象 | 形 |
|---|---|---|
| バックシーム | 補強以外の全部位 | Smooth(0.005 × 大きさ − \|u − 0.5\|, 0.0015) |
| ドット | 脚（フェイクではソックス部 s > 境目） | 1 周に round(14／大きさ) 個（最低 2）、0.07 × 大きさ ごとの段、奇数段は半個ずらす。各升で半径 0.27 の円（ぼかし 0.03） |
| 猫 | 同上 | 1 周に round(8／大きさ) 個、0.12 × 大きさ ごと。各升に猫の頭（半径 0.25 の楕円、耳は頭の上の三角、目は穴） |

フェイクサイハイの境目の飾り（上部・ソックスの帯）:

- レース: 上部に 1 周 16 個のスカラップ（高さ 0.06）。中に網目（周り 72、長さ 0.018）の穴。帯は網目で半分抜く。
- 波: 上部で、境目からの高さが 0.035 × (0.5 + 0.5 cos(7 × 2π u)) + 0.004 未満の所（ぼかし 0.003）。
- 猫: 脚の前に、境目の上へ出る 2 つの耳（大きさ 1.7 倍の座標で高さ 0.085、底の半幅 0.042、前から ±0.066 に、内側に小さな透ける窓）。

伝線: 決まった乱数（SplitMix64。種は伝線の種、各値は上位 53 ビット ÷ 2^53）で、1 本ごとに「右脚か（< 0.5）」「u0」「始まり s0 = 0.2 + 1.4 × 乱数」「長さ = 0.15 + 0.5 × 乱数」の順に引く。線の形: 幅 = 0.004 × sin(π × 長さ方向の割合)、横の距離 = |u − u0（周期 1）− 0.0015 × sin(400 s)|、Smooth(幅 − 距離, 0.0015)。

## 7. 着せ方

### 7.1 頂点の結び付け（Blender 側の最終段）

1. 厚みを付けた後の面を評価して配列にする。
2. 各頂点を体に結び付ける: 肌に沿う頂点は元の肌の点を結び付ける（厚みで増えた頂点も元の頂点の情報を受け継ぐ）。それ以外（つま先の差し替えで増えた頂点）は、自分の位置から布の法線の逆向きに 15 mm 以内の「まっすぐ下の体の点」に結び付ける（当たらなければ最近点）。最近点だと、指の間を渡る所で隣り合う指の間を飛び、写しの肌の色が引き伸ばされ、ウェイトも混ざるため。
3. 角ごとの UV: 面の角の肌の点の平均を結び付けた三角形を「面の基準の三角形」とし、全ての角の UV をその三角形の UV から求める（基準と違う三角形の角は、基準の三角形での切り詰めない重心座標で外挿）。これで 1 つの面が 2 つの UV の島にまたがらない。
4. 出力の頂点 = (頂点, 法線を 1e-3 で丸め, UV を 1e-5 で丸め, 脚の座標を 1e-5 で丸め) の組で一意な物。
5. 法線の置き換え: 肌からの距離が 基本の浮き + 1.5 mm 以内の頂点は、体の滑らかな法線（布の法線と向きを揃え、内積 0.3 超の時だけ）へ、w = clamp((基本の浮き + 1.5 mm − 距離)／1.5 mm) の割合で寄せる。橋渡しの所、張った指先・つま先の区域（5 本指でない手袋の指先全体）は布自身の法線を保つ。

### 7.2 メッシュの組み立て（Unity）

| 要素 | 内容 |
|---|---|
| 頂点・法線 | Blender の値（体のメッシュ空間） |
| インデックス形式 | 頂点 65,535 超なら 32 ビット |
| UV0 | (伸びの倍率をランプ用に写した値, 0.5)。写し方: 0.02 + 0.96 × clamp01(値) |
| UV1 | 柄の座標（第 6.9 節） |
| UV4（0 始まりで 4） | 脚の座標 (s, u) そのまま |
| UV3（0 始まりで 3） | 姿勢の伸びの k（第 6.6 節、使う時だけ） |
| サブメッシュ | 2 層式なら先頭に全三角形（裏地用）。続いて部位の番号順に、三角形がある部位だけ |
| バインドポーズ | 体のメッシュの物をそのまま |
| 接線 | 再計算（姿勢の伸びを使う時は第 6.6 節で上書き） |

### 7.3 ボーンウェイトとシェイプキー

- 基本: 結び付けた体の三角形の 3 頂点のウェイトを、重心座標で重み付けて足す。
- 下に着ている物の上: 第 8.3 節の割合で、その衣装のウェイトへ寄せる（基本 × (1 − 割合) + 衣装 × 割合）。
- 下の衣装の面から作った頂点（Blender が記録した物）: その衣装の三角形の 3 頂点のウェイト（体の骨の番号に直した物）を重心座標で足した物を、割合 1 で使う（どの姿勢でも衣装の上に留まる）。どれかの骨が体に無ければ使わない。
- ガーター・レッグラップ: 体のウェイトだけを使う（下の層の服のウェイトは左右の脚や腰が混ざることがあり、受け継ぐと帯が左右の脚にまたがって動く）。
- 足の指の骨のウェイトをならす（つま先をまとめて包む種類〔5 本指以外〕で、足の指ごとに骨を持つ体）: 足の指の骨のウェイトを持つ布の頂点と、その 2 周外のウェイトを、布の上で隣の頂点の平均と半分ずつ混ぜる（4 回。同じ位置の頂点は毎回そろえる）。指ごとに違う角度に曲げたとき、まとめた面が指ごとに裂けないように、指の間を渡る布を両隣の指の中間で動かす。回数を多くすると強く曲げた指に布が付いていかず、指の間だけに絞ると境目で小さな三角形が裏返る。
- 大きい順に 4 本を取り、和で正規化。和が 0 なら骨 0 に 1。
- シェイプキー: 体の全シェイプキーの全フレームについて、頂点と法線の差分を重心座標で補間する。布のどこかで動きがある（差分の 2 乗が 1e-14 を超える）物だけを、同じ名前・同じフレームの重みで加え、「同期するシェイプキー」として記録する。

### 7.4 肌の写し

透ける布の内側に、体と同じ見た目の肌を描く別のメッシュです。布と同じ頂点・ウェイト・シェイプキーを持つので布と一緒に動き、どの姿勢でも肌が布から出ません（その代わり、元の肌は消します）。

- 写す部位: マテリアルが透ける（描画順 2450 以上）部位。不透明の部位は肌を隠すので写さない（フェイクサイハイのソックス部など）。
- 除く所（下の衣装の肌を残す場合）: 頂点が下の衣装の面から作られた物、または結び付けた三角形の角（重心座標 > 1e-4）に「衣装が本当に乗っている肌」がある三角形。引っ張り透けの布では除かない（下着も隠すため写しで覆う）。
- 前に作った親指サックの下: 体の頂点のうち、今の姿勢の法線の向きに 4 mm 以内で親指サック（作った衣装のうち名前が `ToeCaps_` で始まる物）の面に当たる物を「サックの下」とし、三角形の 3 頂点とも結び付け先の角がすべてサックの下なら写しを作らない（写しは布の面にあり、下のサックを隠す。縁にかかる三角形は残すので肌は出ない）。親指サック自身にはこの除外を行わない。
- 三角形を、結び付けた体の三角形が属する体のサブメッシュごとにまとめ、サブメッシュとする。UV0 は体の UV、UV1 は無し。三角形が無ければ写しは作らない。
- 足の指先: 足先の布は体の指と 1 対 1 に対応しないので、体の UV で描くと爪の模様（ペディキュアなど）が伸びて崩れる。足の指の付け根（Toes の骨）より前（足首から付け根への向きを、脚の上下に垂直にした向き）で、付け根から足首〜付け根の長さの 1.5 倍以内の体の頂点を指先とし（各頂点は近いほうの足で調べる）、結び付け先の角がすべて指先の頂点を指先の頂点とする。3 頂点のうち 2 つ以上が指先の三角形は、同じ体のサブメッシュでも別のサブメッシュにまとめ、メインテクスチャを外して脚の肌の平均色にしたマテリアルで描く。Toes の骨が無いアバターでは行わない。
- マテリアル: 体の各スロットのマテリアルを複製し、アウトラインを外す（シェーダー名に Outline を含めば外した名のシェーダーへ。描画順は保つ。アウトライン幅は 0）、アルファマスクを切る、描画の深さを少し奥へずらす。体にスロットが足りなければ最後の物、全く無ければ写しは作らず警告。

### 7.5 装着

1. アバターのルートの下に、物の名の空のオブジェクト（衣装）を作る（元に戻す操作の対象）。
2. 骨格を写す: ボディが使う骨（とルートボーン）からアバターの骨格の根までの経路にある骨だけを、名前・ローカルの位置・回転・拡大ごと写す。写しの根は元の骨格と同じワールドの位置・回転にする。ボディが自前の骨格を持つ場合は、その骨も対応するアバターの骨の写しへ対応させる。
3. 布の描画物: 衣装の下に子を作り、ボディの描画物と同じワールドの位置・回転・拡大にする。骨は写しへ差し替え、マテリアルを付け、描画の設定（境界、光と反射のプローブ、影、画面外更新）をボディから写す。同期するシェイプキーの値をボディの今の値にし、Modular Avatar のシェイプキー同期を付ける。
4. 肌の写しがあれば同様にもう 1 つ。
5. ボディのオブジェクトがアバターのルートでなく、ルートの中にあり、均一に拡大され（3 軸の差 1% 未満）、骨格の中でなければ、衣装をボディのオブジェクトの下へ移す（ボディと一緒に表示・非表示）。
6. Modular Avatar があれば「衣装のセットアップ」を行う（ビルド時に骨格を結合）。
7. ガーター・レッグラップは、布の描画物の「影を受ける」を切る。

### 7.6 シュリンク系シェイプキー

衣装を着た状態で保存されたアバターには、衣装の下の肌を縮めて隠すシェイプキーが入っていることがあります。名前ではなく働きで判定します。今の値が 0 でない各シェイプキーを、最後のフレーム（最大値）で調べ、次のどれかに当たる頂点が 10 以上あれば「シュリンク」とし、値を 0 にします。

- 頂点の移動が 10 mm を超え、かつその頂点の最長の辺の 2 倍を超える（針状に引っ張る）。
- 三角形の面積が元の 5% 未満になる。
- 三角形の 3 頂点の移動の法線方向の和が負（内向き）で、面積が元の 40% 未満になる（靴に合わせて細くした足首など）。

### 7.7 肌の削除（AAO の箱）

AAO の「箱の中のメッシュを消す」部品で、布に隠れる肌を消します。

条件: 「肌を消す」（第 6.4 節）が真、AAO がある、肌の写しが要るのに作れなかった場合でない。

1. 下の衣装を透かして見せる場合（布が透ける、またはフェイクで上部が透ける）で肌の写しを使い、下の衣装があれば、「衣装がある所とその周り」の肌は残す（覆う距離を −1 にする）。さらに、その肌が衣装に合わせて動くよう、第 8.5 節の部品を付ける。
2. 消す頂点: 覆う距離 ≥ 余裕。加えて、消す頂点を含み、3 角の覆う距離の最小が 余裕 × 0.25 以上の三角形の全頂点（余裕の帯から深く入り込む細長い三角形が、関節を曲げた時に刺として出るため）。
3. 位置は今の姿勢・シェイプキーでのボディのローカル座標。
4. 箱の当て方:
   - 骨盤: 消す頂点のうち腰の中心より上の物を、上方向に 10 等分した薄切りにする。
   - 各脚: 腰の中心より下でその側の物を、股関節・膝・足首と、足の最も前の点（足首より下の点の平均方向を水平化した前で最も前の点）の連鎖の、最も近い区間に分け、区間の軸方向に 10 等分する。
   - 薄切りの箱: 軸と横から作った向きの座標で境界箱（± 1e-5）を作る。残す頂点が中に入れば、半分に割る（最大 3 段）。割っても駄目なら捨てる。点が 3 未満の薄切りは作らない。
   - 補い: 3 角とも消すのに、まだどの箱にも入っていない三角形を、重心の 2 cm（ローカル単位に換算）の升で集め、軸に平行な箱で囲む。残す頂点が入るなら三角形ごとの箱にする（それでも入るなら諦める）。
5. 布が不透明なら、下に着ている物も同じように消す（その衣装の頂点の覆う距離は、2 cm 以内の最も近いボディ頂点の値）。透ける布では衣装を見せるので消さない。

### 7.8 リボンの垂れの揺れ物（ガーター）

`output.json` の `swing`（出力の頂点・垂れの番号・根元からの割合の 3 つ組の並び）から、垂れごとに:

1. 垂れの頂点の今の位置から、根元（割合 0）と先（割合 1）の平均位置を求める。
2. 根元の頂点で最も重い骨（太ももの骨の写し）を親として、根元から先へ 3 つの骨を連ねる（向きは根元→先）。骨とバインドポーズ（今の姿勢をバインドポーズとする）をメッシュに足す。
3. 垂れの各頂点のウェイトを、割合で隣り合う 2 つの骨に配る（根元は最初の骨だけ）。
4. 根元の骨に VRChat の揺れ物（VRCPhysBone。型は名前で探し、SDK への参照を持たない）を付ける: pull 0.2、spring 0.3、stiffness 0.1、gravity 0.3。SDK が無ければ警告だけ。

## 8. 下に着ている物・上に着ている物の扱い

### 8.1 検出

ボディ以外の、有効で表示されているスキンメッシュ（このツールが作った物を除く）について、今の姿勢でのワールド座標で調べます。腰の中心より「胸の高さの半分」上を「ウエスト」とします。

1. ウエストより下の頂点を数え、それぞれ 1.5 cm 以内の最も近いボディ頂点を探す。その脚の重みが 0.3 以上なら「脚の上」と数える。肌の法線方向の高さ h が 0 < h ≤ 10 mm なら記録し、その肌が股関節より上なら「腰」と数える。
2. 記録が 30 未満なら候補外。
3. 太ももをどこまで下りるか: 肌から 25 mm 以内の頂点について、近い方の太ももの軸（股関節→膝）での割合（正の物）の 95 パーセンタイル。
4. 密着率 = 記録数 ÷ 脚の上の数。
5. 腰を覆う = 記録数 ≥ ウエストより下の頂点数 × 0.5 かつ 腰の数 ≥ 30。
6. 分類:

| 分類 | 条件 | 既定の扱い |
|---|---|---|
| 下に着る物（下着・パンスト） | 腰を覆う・高さの中央値 ≤ 4 mm・下り < 0.22 | 布をその上に重ねる |
| スパッツ | 腰を覆う・下り ≥ 0.22・密着率 ≥ 0.96 | 無いものとして扱う（上にも下にもしない） |
| その他（靴下・スカート・ドロワーズなど） | 上記以外 | 布をその下に作る（上の衣装） |

ウィンドウでは検出結果ごとに「上に重ねる」を利用者が選べます（選択はアバター内の経路で覚える）。

### 8.2 高さの計算（Unity）

- 下の衣装の高さ（重ねる物）: 各ボディ頂点から法線方向へ 25 mm までの光線を、衣装の三角形（1 cm 格子で探す。4,096 升を超える大きな三角形は除く）に当て（両面）、最も遠い当たりの距離。さらに衣装の各頂点が、1.5 cm 以内の最も近いボディ頂点の高さを自分の高さ（0 < h ≤ 25 mm）まで上げる（フリルのひだの間を光線がすり抜けるため）。
  - 「乗っている」= 高さ > 0。「周り」= それを 3 輪広げた物（座る時に衣装が肌の上を滑るため）。広げる時、同じ位置の頂点（UV の継ぎ目）は揃える。
  - 「覆われ具合」= 乗っている所 1、それ以外 0 を、「自身と隣の平均の小さい方」で 2 回（縁の 1〜2 頂点で 1→0 にぼける）。
  - 高さは「自身と隣の平均の大きい方」で 4 回（縁の外へ少し広げ、布が段にならず斜めに乗り上げるように）。継ぎ目は最大で揃える。
- 上の衣装の天井（重ねない物、スパッツを除く）: 法線方向へ 10 mm までの最も近い当たり。1 輪外へ、隣の低い方の天井で広げる。

### 8.3 下の衣装の面とウェイト

- 下の衣装の面（Blender へ送る）: 衣装の各頂点について、1 cm 格子で近いボディ頂点を探し、その周りの三角形上の最近点を取る。12 mm を超えて離れた頂点（浮いたフリル）とその三角形は除く。残りは「ボディのメッシュ空間で、補間した頂点位置 + 補間した法線 × (法線方向の高さ ÷ 1 単位あたりのメートル)」に置き直す（ボディのバインド空間での形にする）。各頂点の体の骨でのウェイトも持つ（骨の対応: 衣装の骨か親の骨がボディの骨と同一か同名。どれかが無ければウェイト無し）。
- ある点での衣装のウェイト（布の頂点用）: 1 cm 以内で、肌と同じ向きを向き（面の法線・肌の法線 ≥ 0.3 × 面の法線の長さ）、肌より 2 mm 以上奥でない、最も近い三角形の最近点の重心座標で、3 頂点のウェイトを足す。複数の衣装では最も近い物。
- 布の頂点が衣装を使う割合 = 結び付けた三角形での「覆われ具合」の補間値（0〜1）。

### 8.4 下の衣装の上に乗せる（Blender）

布の頂点のうち、元の肌の点に下の衣装の高さ w > 0 がある物について（ガーター・レッグラップでは行わない）:

1. すでに w + 基本の浮き + 2.5 mm + 2 mm より高く浮いている（お尻の橋など）なら、動かさず結び付けだけ行う。
2. 推定点 B + N × w の近く（w + 3 mm 以内）で、下の衣装の面の最近点 P と法線を取る（法線は肌の法線と同じ向きに揃える）。法線の内積が 0.6 未満、または P が肌の法線の線から w + 2 mm を超えて横にずれていれば使わない。
3. 必要な高さ = (P − B)・N + 基本の浮き + 2.5 mm。これより低ければ法線に沿って持ち上げる（下げない。横へは動かさない）。結び付けとして衣装の三角形番号と P の重心座標を記録する（Unity でその衣装のウェイトを使う）。
4. 太ももの間の窪みなどで面が折れるので、最大 10 回: 面の法線が持ち上げ前と 60 度を超えて変わった面の頂点と隣を、隣の平均との中点へ（縁を除く）移し、必要な高さを下回れば戻す。必要な高さを記録していない頂点も、肌からの高さが基本の浮きを下回れば法線方向に戻す。

### 8.5 衣装の下に残した肌を衣装に合わせる

透ける布で下の衣装を見せる時、衣装が本当に乗っている肌の頂点は、衣装のウェイト（その点の衣装のウェイトの上位 4 本、正規化）で動かすようにします（そうしないと衣装と肌が別々に動き、肌が衣装から出る）。周りの輪の肌は自身のウェイトのまま（衣装に引かれると隣の肌から裂けたため）。

この対応（ボディ頂点 → ウェイトの組）を、衣装のオブジェクトに付ける独自の部品に「頂点番号の列・各頂点の本数の列・骨番号の列・重みの列」として保存します。ビルド時（NDMF の変換の段、AAO の最適化より前）に、ボディのメッシュの複製へこのウェイトを書き込み、部品を消します。部品の値がメッシュに合わない（列の長さの不一致、本数が 1〜255 の外、範囲外の頂点・骨）なら書き換えず警告します。エディターでも NDMF のプレビュー（レンダーフィルター）で同じ結果を表示します（部品自体の定義は実行時側。詳細設計 S 3）。

### 8.6 小物（ガーター・レッグラップ）の下の層と上の服

- 「タイツ・靴下の上に付ける」がオンなら、前に作った脚の衣類（表示中で、名前が `Tights_` `Spats_` `ThighHighs_` `KneeHighs_` で始まり `_Mesh` で終わる、出力フォルダのメッシュを描く物。肌の写しは除く）を下の層に加える。さらに「アバターの靴下・レッグウォーマーの上にも巻く」がオンなら、検出された衣装のうちスパッツでなく太ももの半ばより下（下り > 0.5）まで届く物（アバター自身の脚の服）も下の層に加える（実物も靴下の上からリボンを巻く。下に収めようとすると服を突き抜ける）。
- 「アバターの靴下・レッグウォーマーの上にも巻く」がオフ（または「タイツ・靴下の上に付ける」がオフ）なら、アバター自身の脚の服は下の層にも上に着る物にも数えない（服を脱がせた状態用）。
- 下の層の高さ（第 8.2 節）と面からの作り直し（第 8.4 節）は使わず、第 5.12 節のとおり仕上げの後に面から直接測って載せる。上に着ている、肌から 8 mm 以内の服の下になる面は最初から作らない（第 4.3 節）。

## 9. 腕の衣類と包む機能

### 9.1 腕の範囲

腕の連鎖: 肩（上腕の付け根）・肘・手首・（あれば）中指の付け根。手の枠: 手首、指先へ向かう向き d = 単位(手首 − 肘)、手の到達 = 手首より先（d 方向の射影が正）にあるその側の点のうち、中指の付け根（無ければ手首）に最も近い点と辺でつながる点だけについての d 方向の射影の最大（腕を下げた体では手首より先に同じ側の脚もあるため）。正でなければ前腕の長さ × 0.7。

指の付け根の少し手前 = 中指の付け根 − d × 到達 × 0.18（無ければ 手首 + d × 到達 × 0.3）。関節の上だと、こぶしを握った時に肌が出るため手前で止める。

| 種類 | 平面 | 種 |
|---|---|---|
| 手袋 | 上端: 連鎖の数 = 手首 1.92／前腕 1.5／肘上 0.55、手側を残す。指なしなら、付け根の手前の切り取りと親指の穴（下記）を追加。絵描き用なら、親指の穴と指の側の切り取りを 1 つの滑らかな形で切る | 手首 + d × 到達 × 0.2 |
| アームカバー | 上端: 連鎖の数 = 上端の位置、手側を残す。手の甲までなら付け根の手前で切り、親指の穴を開ける。手の甲までないなら連鎖の数 1.97 で肩側を残す | 連鎖の数 1.5 の点 |

滑らかな形（第 4.4 節）の定義:

- 親指の楕円体: 軸 u = 親指の付け根→中間の関節（長さ L）。太さ = 付け根から 0.6〜1.0 L で軸から 1.2 L 以内の体の点の、軸からの距離の中央値（8 点未満なら 0.5 L）、半径 r = max(0.55 L, 太さ × 1.6)。先 = 付け根から 6 L 以内・軸から太さ × 1.2 以内の点の u 方向の最大 + 0.3 L（2.55 L 以上）。楕円体は u 方向に 0.25 L から先まで、太さ方向の半径 r。
- 絵描き用: 指の側の切り取り量 = 丸めた min((p − 付け根の中点)·fd, (p − 仕切りの点)·across)。fd = 中指の付け根→中指の先の関節（無ければ d）、仕切りの点 = 中指の付け根 − (人差し指 − 中指の付け根) × 0.5、across = (人差し指 − 中指の付け根) の fd に直交する成分の向き、丸めの半径 = 人差し指と中指の付け根の間 × 0.5。親指の穴と丸めた max（半径 到達 × 0.15）で合わせる。人差し指か中指の付け根が無ければ親指の穴だけ。
- 付け根の手前の切り取り（指なし・手の甲まで）: 平面と親指の穴を丸めた max（半径 到達 × 0.15）で合わせる（平面が親指の付け根を斜めに横切ると、親指の股に尖った布が残るため）。親指の骨が無ければ平面だけ。

腕の衣類は、つま先・お尻の処理を行わず、残す成分は種の物だけです（島の扱いは第 4.3 節）。伸びの透けは第 6.2 節の腕の式。部位分けは上端の帯だけが当たり得ます（帯の幅は脚の長さに比例したまま）。姿勢の伸びは使いません。肩か手が無い腕は作りません。

### 9.2 包む機能の対象の自動選択

アバターの中のスキンメッシュ（ボディとこのツールが作った物を除く）から、次の全てを満たす物を、上下の幅が大きい順に並べます。

- ウェイトの 8 割以上が「Hips の子孫で、背骨と左右の大腿骨の子孫でない骨」（しっぽの骨など）。
- 上端が Hips より上へ「太ももの長さ × 0.3」以内、下端が Hips より「太ももの長さ × 0.5」以上下、かつ膝より下まで届く（高さはワールドの Y）。
- 両脚を囲む: 横方向に股関節間の半分以上ずつ左右へ、前後に股関節間 × 0.25 以上ずつ前後へ広がる。
- 下が閉じている: 開いた辺（位置で溶接した上で、1 つの三角形にしか属さない辺）の頂点が、全て上から高さの 1/3 以内。

### 9.3 包む布の作り方（Blender を使わない）

1. 体は読めれば読む（失敗してもよい。マテリアルの肌色に使うだけ）。対象が無ければ失敗。
2. 1 単位あたりのメートル = 各骨の「ワールド行列 × バインドポーズ」の拡大の x の中央値（骨が無ければオブジェクトの拡大）。
3. 浮き = (隙間 + 厚み) mm を単位に換算。
4. 同じ位置の頂点の法線（正規化）を合計し、和の長さが「本数 × 0.2」を超えればその向き、そうでなければ自身の法線（薄いひれの縁で打ち消し合う所）に、浮きだけ動かす。
5. メッシュ: 三角形は全サブメッシュを 1 つに。UV0 は伸びなし（倍率 1）、UV1 は 0。ウェイト・バインドポーズ・全シェイプキー（接線の差分も）は対象のまま。
6. 設定のうち、姿勢の伸び・柄・フェイク・2 層式・グラデーション・伝線・引っ張り透けを切り、部位「脚」1 つのマテリアルを作る。
7. 対象のオブジェクトの子として置き、同じ骨・ルートボーン、描画の設定を写し、シェイプキーの値を写して同期を付ける。

## 11. 制約・既知の限界

- 対象は Humanoid のアバターだけ。Hips・左右の大腿・下腿・足、Spine か Chest が無いと作れない。
- 体のメッシュに肌が無い所（衣装で隠れる所を省いた作り）には布を作れない。ウィンドウは警告するだけで、布は体の切り口の少し内側でまっすぐに切りそろえた筒になる。
- 脚の肌にタイツなどが描き込まれた体では、透ける布の下にそれが見える（警告のみ）。
- Blender 5 以上が必要で、内蔵の表で判定するため、表に無い新しい版は警告、古い版は使えない。Blender の自動検出は Windows の登録と Program Files に依存する。
- lilToon が無いと、透け・柄・質感の無い Unity 標準のマテリアルになる。Modular Avatar が無いと、骨格の結合・シェイプキー同期・自前の骨格の結合先の対応が働かない。AAO が無いと肌を消さない。VRChat SDK が無いとリボンの垂れは揺れない。
- 処理時間の打ち切り（既定 60／90 秒）を超えると失敗する。範囲外の細かさ・隙間・厚みは Blender 側で拒む。
- 品質の報告は数えるだけで直さない。小さな穴は縁の辺が 24 本以下の時だけ塞ぐ。つま先の縫い合わせで輪が見つからない足はつながず、警告だけ出す。
- つま先の面は「まとめ」「足袋型」の時だけ作る。5 本指では体の指の形がそのまま布になり、体の指が分かれていなければ分かれない。足袋型は体の親指と人差し指が離れていない足では「まとめ」と同じ。足の指の骨の無い体の 5 本指では指先の張りを行わない。
- 親指サックは、体の足の指が分かれていなければ指先の内側を親指として切る。
- お尻の橋渡しは後ろ側だけで、前の股は肌に沿う。
- 「股の見た目を優先」では、浮いた下着の一部が布から出ることを許す。
- スパッツと判定された衣装は、タイツと一緒に穿かない物として無いものとして扱う（見た目が崩れることがある）。
- 腕の衣類では姿勢の伸びを使わない（静的な伸びだけ）。部位の大きさ（帯の幅など）は脚の長さに比例したまま。
- ガーター・レッグラップは、太ももの内側どうしが付け根まで触れる体では、股の間に少し布が残る。帯は体のウェイトだけで動くので、下の層のタイツが下着のウェイトで動く所とはずれ得る。
- 包む機能は高さをワールドの Y で判定するので、アバターが傾いていると候補判定がずれる。柄・伸び・2 層式などは使えない。
- ニーハイの上端が膝関節の上（0.9〜1.1）だと、曲げた時に口ゴムが浮き沈みする（警告のみ）。
- ジョブの `opaque` と `poseStretch` は Unity が書き出すだけで、Blender 側では読まない。
- 姿勢の伸びの係数は 1 つの姿勢（股関節 70・膝 100・足首 30 度）で較正しているので、別の姿勢では誤差が出る。
