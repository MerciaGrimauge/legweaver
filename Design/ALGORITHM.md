# LegWeaver アルゴリズム仕様

この文書は、LegWeaver が「何を入力に、何を、どの順で、どんな基準と数値で行い、何を出力するか」を、
コードを読まずに同等の機能を実装できる粒度で書き出した仕様である。
実装の文をそのまま写したものではない。括弧内の関数名・ファイル名は参照用で、仕様の一部ではない。

## 0. 表記と約束

- **体のメッシュ**: アバターの肌を描く SkinnedMeshRenderer（以下「体」）。
- **メッシュ空間**: 体のメッシュの頂点データそのものの座標系（バインドポーズの空間）。Blender 側の処理はすべてこの空間で行う。
- **ワールド（現在の姿勢）**: 体を現在のボーン姿勢とシェイプキー値でスキニングした位置。Unity 側の衣装・下着の判定はこちらで行う。
- **mpu**（meters per unit）: メッシュ空間の 1 単位が何 m か（3.4）。文中の「mm」はすべて実寸で、メッシュ空間では `mm / 1000 / mpu` に換算して使う。
- **上方向 up**: 両足首の中点から両股関節の中点へ向かう単位ベクトル。
- **横方向 lateral**: 右股関節から左股関節へ向かうベクトルを up に直交化した単位ベクトル（左が正）。
- **前方向 fwd**: 足のボーン→つま先のボーン（左右平均）を水平にしたもの。つま先のボーンが無ければ `up × lateral`。
  場面によっては、メッシュの足の点から求めた足の向き（5.1.2 の foot_frame の前方向、左右の平均）を使う（その都度書く）。
- **左右の判定**: 点 p について `(p − 股関節中点)·lateral ≥ 0` なら左（+1）、そうでなければ右（−1）。
- **脚の鎖**: 股関節(0) → 膝(1) → 足首(2) → つま先(3、ボーンがあれば) の折れ線。鎖のパラメータ s は区間番号＋区間内の割合。
  第 1 区間の手前（股関節より上）だけは負の値まで延ばす。点の鎖パラメータは、最も近い区間への射影で決める（chain_param）。
  `chain_point(s)` は鎖上の点と「股関節側を向く」区間方向を返す（鎖の外の s は端の区間を延長する）。
- **腕の鎖**: 肩(0) → 肘(1) → 手首(2) → 中指の付け根(3、あれば)。
- **脚の長さ** leg_len: 左股関節から左足首までの距離。**腰の幅** hip_w: 左右の股関節間の距離。
- **smoothstep**: `f²(3 − 2f)`。**Smooth(d, w)**（柄で使う）: `smoothstep(0, 1, clamp01(d / w + 0.5))`。

## 1. 全体像

### 1.1 入力

| 入力 | 内容 |
|---|---|
| アバター | Humanoid の Animator を持つルート。シーン上のオブジェクトか .prefab。.prefab ならシーンに配置してから処理する（アセット自体は変えない） |
| 体のメッシュ | 自動選択（3.1）か手動指定 |
| 体以外のメッシュ | 下着・靴下などの検出対象（4 章） |
| 設定 | 2 章 |
| 外部ツール | Blender（必須。バックグラウンド実行）、VRChat SDK（必須。実行時の部品が使う）、NDMF（必須。下着の下の肌の追従）、lilToon（必須。同梱のシェーダーの土台。読み込めないときは Standard シェーダーで代わりに作る）、Modular Avatar（必須。衣装をアバターのボーンに統合する）、Avatar Optimizer（任意。肌の削除に必要） |

### 1.2 出力

- 体のレンダラーのオブジェクトの下に衣装オブジェクト `<種類>_<デニール>D`（種類: Tights / Spats / ThighHighs / KneeHighs / Gloves / ArmCovers）。
  体のレンダラーがルートにある場合、体のオブジェクトの拡大率が軸ごとに 1% 以上違う場合、体のオブジェクトが骨組みの中にある場合は、ルートの下。
  体のオブジェクトと一緒に表示・非表示が切り替わる（GameObject の有効・無効の場合。レンダラーの有効・無効には従わない）。
  - 子に、体が使うボーンだけを複製したアーマチュア（名前・ローカル変換は元と同じ）。
  - 子に `<名前>_Mesh`（衣装の SkinnedMeshRenderer）。肌の写しを使うときは `<名前>_Skin`（肌の写しの SkinnedMeshRenderer）。
  - Setup Outfit（ビルド時に元のアーマチュアへ統合）と、各レンダラーに MA Blendshape Sync。
  - 下着の下の肌を追従させる場合は SkinFollow コンポーネント（6.6）。
- 「包む」（9 章）では、包むメッシュのオブジェクトの下に `Wrap_<デニール>D`（SkinnedMeshRenderer。アーマチュアは作らない）。
- 体のレンダラー（と、不透明時は下着のレンダラー）に AAO Remove Mesh By Box（6.5）。
- アセット: `Assets/LegWeaver_Output/<アバター名>_<名前>_<日時>/` にメッシュ・マテリアル・テクスチャ。
- 体のシュリンク系シェイプキーの値を 0 にする変更（3.5。Undo 可能）。
- すべての変更は Undo できる。

### 1.3 処理の流れ

1. **Unity: 準備**
   1. Humanoid の確認、体のメッシュの選択、体の読み込み（頂点・法線・UV・三角形・脚ウェイト・関節の混ざり・ランドマーク・mpu）。
   2. シュリンク系シェイプキーを 0 にする（設定でオンのとき）。
   3. 衣装を考慮するモードなら、体以外のメッシュから「下に着ている物」「上に着ている物」を検出し、下着の高さ・下着の面などを計算する。
   4. 体のデータと設定を作業フォルダに書き出し、Blender をバックグラウンドで起動する（打ち切り時間あり）。
2. **Blender: 生成**（5 章）
   1. 平面で体を切って覆う範囲を取り出す。
   2. 範囲を閉じた SDF の外形（エンベロープ）、足先用の SDF、お尻の橋渡し用の SDF を作る。
   3. 範囲の各頂点を体の法線方向へ持ち上げる（隙間＋厚み＋下着の高さ＋関節・裾の余裕、溝・上着の制限、お尻の橋渡し、外形への持ち上げ）。
   4. 足先（まとめ）を SDF の面に置き換えて縫い合わせる。
   5. 崩れの修正（しわ取り、こぶ取り、お尻の外形の制限、たるみ、小穴埋め）。高品質なら細分化。
   6. 実物の構造に合わせた部位分け。
   7. 下着の面からの作り直し（下着の上の頂点）。折れのならし。
   8. 縁の厚み付け、出力（頂点の体への結び付け、UV、脚の座標、伸びのマスク、品質検査）。
3. **Unity: 組み立て**（6・7 章）
   1. 結び付けからボーンウェイト・シェイプキーを補間してメッシュを作る。
   2. マテリアル・テクスチャを作る。
   3. 肌の写しを作る（使うとき）。
   4. アバターに追加する。姿勢による透けのデータを入れる（使うとき）。
   5. 肌の削除（AAO の箱）と下着の下の肌の追従（SkinFollow）を付ける。

### 2.2 設定から決まる判定

以下の判定が、形・削除・マテリアルの分岐に使われる。c(d) はデニール d の被覆率、不透明の閾値は 0.95。

| 判定 | 条件 |
|---|---|
| 不透明（形・削除の基準） | 2 層式、または c(デニール) ≥ 0.95 |
| 引っ張りで透ける | 不透明 かつ 2 層式でない かつ フェイクサイハイでない かつ 強さ > 0 かつ デニール < 200 |
| 実効の伸びの強さ | 引っ張りで透けるなら `伸びによる透け × 引っ張りの強さ × clamp01((200 − デニール) / 140)`（80D で 0.857 倍）、それ以外は「伸びによる透け」 |
| 見た目が透ける | 2 層式なら c(見かけのデニール) < 0.95。それ以外は「不透明でない」または「引っ張りで透ける」 |
| 見た目の被覆率 | 2 層式なら c(見かけ)、引っ張りで透けるなら 1、それ以外は c(デニール) |
| フェイクサイハイ | 設定オン かつ 種類がタイツ。上部が透ける = c(上部のデニール) < 0.95（上部のデニールは 5〜60） |
| 姿勢による透けを使う | 設定オン かつ 腕の衣類でない かつ（見た目が透ける または フェイクサイハイで上部が透ける）かつ 実効の強さ > 0 |
| 肌の写しを使う | 設定オン かつ 2 層式でない かつ（見た目が透ける または フェイクサイハイで上部が透ける） |
| 肌を削除する | 「常に」、または「自動」で（不透明 または 肌の写しを使う） |
| 下着を内側に収める | （不透明 かつ フェイクサイハイでない）または「内側に収める」を選択 |
| Blender へ渡す伸びの強さ | （見た目が透ける または フェイクサイハイ）かつ 引っ張りで透けないなら実効の強さ、それ以外は 0 |
| Blender へ渡す足指の埋め幅 | 5 本指なら 0（＝足先を SDF にしない） |

## 3. 体の解析（Unity 側）

### 3.1 体のメッシュの選び方

アバター配下の全 SkinnedMeshRenderer（非表示も含む。本ツールの生成物＝メッシュが出力フォルダにある物は除く）について:

- **ボーンの読み替え**: アバターの骨組み（Hips の親。それがアバターのルートか、親が無ければ Hips）の外にあるボーンは、
  その骨組みに Modular Avatar の Merge Armature があれば、まずその規則（接頭辞・接尾辞を外し、統合先からたどる）で読み替え、
  見つからなければ骨組みの中の同じ名前のボーン（幅優先で最初に見つかった物）と見なす。Modular Avatar の Merge Armature で
  ビルド時に統合される、自分の骨組みを持つ体（体だけの部品のプレハブなど）を扱うため。見つからなければ「その他」。
- ボーンを「太もも」（左右の UpperLeg とその子孫のうち LowerLeg の子孫でない物）、「膝下」（LowerLeg とその子孫）、「その他」に分ける。
- 頂点ごとに太もも・膝下のウェイトの合計を求め、太もも ≥ 0.5 の頂点数と膝下 ≥ 0.5 の頂点数を数える。
- スコア = 2 つの数の小さい方。スコア > 0 の物が候補。
  （体は脚全体を覆うので両方が多い。靴・膝下の靴下・ズボンは片方しか多くない。）
- 候補を「表示中（レンダラーが有効で、そのオブジェクトからアバターのルートまでの各オブジェクトが有効。プレハブのアセットでも同じに判定）」と
  「非表示」に分け、表示中の組を先に並べる。各組の中で:
  - 太もも・膝下の頂点を最大約 3000 個取り出し、それぞれの所属する骨（股関節→膝、膝→足首の線分）からの距離 r を測る。
  - 候補 A の点ごとに、候補 B の 2 cm 以内の最も近い点と r を比べる。比べられた点が 20 個以上あり、その 60% 以上で
    A の r が B より 0.1 mm を超えて大きければ「A は B の外側」。
  - 点が 20 個以上あり、どの候補の外側でもない物を先に（スコアの大きい順）、それ以外を後に（スコアの大きい順）並べる。
  - 先頭を体とする。（サイハイの靴下やレギンスも脚全体を覆うが、必ず肌の外側にある。体のポリゴンが粗いと頂点数では
    衣装に負けるため、内外で決める。）

手動指定があればそれを使う。体の脚の肌（太もも・すねのボーンの重みが 0.5 以上の頂点）が、股関節から膝までの 10% より下から始まっていれば「腰から太ももの上の肌がない」、足首から膝までの 15% より上で終わっていれば「膝から下の肌が途中までしかない」と警告する（肌の無い所には作れず、切りっぱなしの筒になる。左右の悪い方）。
また、脚の肌（脚のボーンの重みが 0.9 以上の頂点）と胴・腕の肌（背骨・胸・腕のボーン）の色（各頂点のマテリアルのメインテクスチャ × 色の Lab）の中央値の差が 20 を超えれば、「脚にタイツなどが描かれている」と警告する（透ける生地では描かれた物が透けて見える）。

### 3.2 読み込むデータ

- 頂点位置・法線・UV0（メッシュの基本形。シェイプキーは適用しない）、三角形トポロジーのサブメッシュの全三角形。
- **脚ウェイト**（頂点ごと）: Hips とその子孫のうち Spine の子孫でない物（腰・脚の系列）のウェイトの合計 ÷ 全ウェイト。
- **関節の混ざり**（頂点ごと）: `1 − 最大ウェイト ÷ 全ウェイト`（1 本のボーンだけなら 0、関節で最大約 0.5）。

### 3.3 ランドマーク

Humanoid の次のボーン位置を、メッシュ空間で求める: Hips、Spine、Chest（無ければ UpperChest）、左右の UpperLeg・LowerLeg・Foot・Toes・UpperArm・LowerArm・Hand、
左右の中指の付け根（MiddleProximal）、中指の先の関節（MiddleDistal）、人差し指の付け根（IndexProximal）、親指の付け根（ThumbProximal）、親指の中間（ThumbIntermediate）。

メッシュ空間の位置は、そのボーン自身のバインドポーズ（体のボーン一覧にあれば）の逆行列で原点を変換する。無ければ、最も近い「体のボーン一覧にある祖先」の
ローカル座標でボーン位置を表し、その祖先のバインドポーズの逆行列で変換する。

必須: Hips、左右の UpperLeg・LowerLeg・Foot、および Chest か Spine の少なくとも一方。欠けたらエラー。

### 3.4 単位（mpu）

`mpu = ワールドでの左 UpperLeg〜LowerLeg の距離 ÷ メッシュ空間での同じ距離`（メッシュ空間の距離が 0 に近ければ 1）。
メッシュの単位系やインポート倍率によらず mm の定数を実寸で扱うため。

### 3.5 シュリンク系シェイプキーの判定（ShrinkShapes）

衣装用に肌を縮めて隠すシェイプキーは、名前ではなく形で判定する。現在の値の絶対値が 1e-4 以上のシェイプキーそれぞれについて、最後のフレームの変位で:

- 頂点の判定: 移動量が 10 mm を超え、かつその頂点につながる最長の辺の 2 倍を超える（針のように引き出す）。
- 三角形の判定: 変形後の面積が元の 5% 未満、または「内向き」（3 頂点の変位と法線の内積の合計が負）で面積が 40% 未満（靴に合わせて足首を細くする形など）。該当三角形の 3 頂点を数える。
- 該当頂点が **10 個以上** ならシュリンクとみなし、値を 0 にする（Undo 可能）。

体型を変えるシェイプキー（脚を細くする等）は面積の大半を保つので外れる。

### 3.6 体の書き出し

Blender へは、頂点位置・法線・UV・脚ウェイト・関節の混ざり・下着の高さ（4.2、m）・上に着た物の高さ（4.3、m）・三角形を、
下着の面（4.4）を別ファイルで、ランドマーク・mpu・設定（2.2 で決まる値を含む）を JSON で渡す。

## 4. 下に着ている物・上に着ている物（衣装を考慮するモード）

「肌のみ」モードではこの章の処理をせず、高さはすべて 0。

### 4.1 検出と分類（UnderLayers.Detect）

前提: 体と各メッシュを**現在の姿勢・シェイプキー**でスキニングしたワールド位置で比べる。体の頂点は 15 mm の格子に入れ、最近傍は 15 mm 以内で探す。
ウエストの高さ = 股関節中点から（Chest、無ければ Spine）までの高さ（up 方向）の半分。

体以外の、有効かつ表示中の各 SkinnedMeshRenderer（本ツールの生成物は除く。前に作った衣装は重ねる物ではなく、作り直す物）について、ウエストより下の頂点（数 = below）それぞれ:

1. 最も近い体の頂点（15 mm 以内）を探す。無い、またはその脚ウェイトが 0.3 未満なら飛ばす。あれば「脚の上」の数 overLegs を数える。
2. 肌からの高さ h = （頂点 − 体の頂点）·体の法線。0 < h ≤ 10 mm なら「肌の上」として高さを記録し、その体の頂点が股関節中点より上なら「腰の上」を数える。

「肌の上」が 30 個未満のメッシュは候補にしない。候補について:

- **太ももへの到達度** down: メッシュの各頂点（最も近い体の頂点まで 25 mm 以内の物）を、近い方の太ももの軸（股関節→膝）に射影したパラメータ t（> 0 のみ）の 95 パーセンタイル。0 = 股関節、1 = 膝。
- **密着度** clinging = 肌の上の数 ÷ max(overLegs, 1)。
- **腰を覆う** = 肌の上の数 ≥ below の半分 かつ 腰の上 ≥ 30。（スカートは腰回りしか触れないので外れる。上下一体の下着も、ウエストより下だけ数えるので残る。）
- **スパッツ** = 腰を覆う かつ down ≥ 0.22 かつ clinging ≥ 0.96。
- **下に着ている物（既定で上に重ねる）** = 腰を覆う かつ 高さの中央値 ≤ 4 mm かつ down < 0.22。
  （パンツは太ももの上部で止まる。ドロワーズ・ブルマー・スパッツはそれより下まで届き、タイツの上に穿く物として扱う。）

利用者は候補ごとに「上に重ねる」を切り替えられる（既定は上の判定）。

- 上に重ねる物 → 下着として 4.2・4.4〜4.6 の対象。
- 上に重ねない物のうちスパッツでない物 → **上に着ている物**（靴下・靴・ズボンなど）として 4.3 の対象。
- 上に重ねないスパッツ → 無いものとして扱う（タイツと一緒に穿く物ではないため。見た目が崩れても構わない）。

### 4.2 下着の高さ（UnderLayers.Heights）

体の頂点ごとに「下着が肌からどれだけ上にあるか」（m）を求める。

1. 下着の全三角形を 10 mm 格子に入れる。体の各頂点から法線方向（両面判定の光線）に 25 mm まで光線を飛ばし、当たった距離の最大を高さとする。
2. 光線はフリルのひだのような薄い部分の間をすり抜けるので、下着の各頂点も、最も近い体の頂点（15 mm 以内）の高さを、自分の高さ `(u − p)·n`（0 < h ≤ 25 mm）以上に引き上げる。
3. 補助の量:
   - **core**: 高さ > 0 の頂点（下着が本当に上にある）。
   - **present**: core を三角形の隣接で 3 リング広げた物（座ると下着が肌の上をずれ、その上の布（肌の写しがない所）も一緒にずれるため、削除した肌が下着の縁の後ろで見えないよう余裕を持たせる）。
   - **covered**（0〜1）: core を 1、他を 0 とし、「自分と隣の平均の小さい方」を 2 回繰り返した物（縁の 1〜2 頂点内側で 0 へ下がる）。
   - 高さ自体は、「自分と隣の平均の大きい方」を 4 回繰り返して縁の外へなだらかに広げる（布が段にならず坂で乗り上げるように）。
   - UV の継ぎ目で分かれた同位置の頂点は、present は論理和、covered は最小、高さは最大で揃える。

### 4.3 上に着ている物の高さ（UnderLayers.Ceiling）

体の各頂点から法線方向に 10 mm まで光線を飛ばし、上に着ている物の三角形に当たった**最短**距離を「天井」とする（無ければ 0）。
天井を持つ頂点の隣で天井が無い（または高い）頂点には、隣の低い方の天井を与える（1 リング広げる）。布はこの天井より内側に収める（5.3.2）。

### 4.4 下着の面（UnderSurface）

Blender で布を下着の面から作り直すため（5.7）、下着をメッシュ空間へ写す。

- 下着の各頂点（現在の姿勢）について、最も近い体の頂点の周りの三角形から最近点を探す（10 mm 格子の 27 近傍）。12 mm より遠い頂点（浮いたフリル）は除く。
- 最近点の重心座標と、その点での体の法線方向の高さ h を求め、メッシュ空間の同じ三角形・同じ重心座標の点から、補間したメッシュ空間の法線方向へ h/mpu 離した点を、写した位置とする。
- 3 頂点とも残った三角形だけを残す。各頂点の**ボーンウェイト**（体のボーン番号に読み替えた物、4.5）も記録する。

### 4.5 ボーンの読み替え（BoneMap）

衣装は自分のアーマチュアの複製を持つことが多い。下着のボーンそれぞれを、体のボーン一覧の中で「同じ物、または名前が同じ物」を祖先へさかのぼって探し、
体のボーン番号に対応させる。どこにも当たらないボーンは不明（−1）とし、不明なボーンを含む頂点のウェイトは「無い」扱いにする。

### 4.6 点での下着のウェイト（UnderLayers.WeightsAt）

指定した点（肌の点とその法線）について、各下着の三角形（重心を 10 mm 格子に入れる）から 10 mm 以内の最近点を探す。ただし:

- 三角形の法線と肌の法線の内積が、法線の長さの 0.3 倍以上（同じ向きを向いている）。
- 最近点が肌の点から法線方向に −2 mm より後ろでない（溝で向かいの面を拾わない）。

最も近い候補の 3 頂点のウェイトを重心座標で混ぜた物を、その点の下着のウェイトとする（不明なボーンがあれば「無し」）。複数の下着では最も近い物を使う。

## 5. Blender 側の生成

### 5.0 前処理

- **溶接**: 位置を `bbox 対角長 × 1e-7` で丸めて同じになる頂点を 1 つにまとめる（UV の継ぎ目の分割を戻す）。まとめた頂点の脚ウェイト・関節の混ざり・下着の高さは最大、天井は最小（0 は「無し」）。
  まとめた結果で頂点が重なる三角形は除く。
- **体の表面**: 溶接後の三角形の BVH と、面積重み付きの頂点法線を用意する。
  **結び付け**（bind）: 任意の点に対して、体の表面の最近点・その三角形・重心座標（0〜1 に切り詰めて正規化）を返す。法線は頂点法線を重心座標で補間して正規化する。

### 5.1 覆う範囲の切り出し

#### 5.1.1 切断平面（種類ごと）

平面は「点・法線・残す側・左右（両方／左／右）」を持ち、左右指定の平面は、面の中心がその側にある面だけを切る。
平面の「符号付き距離」は残す側が正。

| 種類 | 平面 | 種（残す連結成分の目印） |
|---|---|---|
| タイツ | ウエスト: 股関節中点 + up × (胸の高さ × ウエストの高さ)、法線 up、下を残す | 左右の膝 |
| スパッツ | ウエスト（同上）＋ 左右の裾: 脚の鎖 s = 裾の位置の点、股関節側を残す | 鎖 s = 裾の位置 × 0.5 の点 |
| サイハイ・ニーハイ | 左右の上端: 脚の鎖 s = 上端の位置の点、足首側を残す | 鎖 s = (上端 + 2) / 2 の点 |
| 親指サック | 5.1.4 | 親指の先端 |
| ガーター・レッグラップ | 5.1.5 | 脚の鎖の帯の中心・巻き始めの点 |
| 手袋・アームカバー | 8 章 | 8 章 |

胸の高さ = 股関節中点から Chest（無ければ Spine）までの up 方向の距離。

#### 5.1.2 足の枠（foot_frame）

**foot_frame**: 足首より下（up 方向）にあるその側の点（10 個以上必要）から、前方向（つま先のボーンがあれば足→つま先を水平化、無ければ体の前方向。
点の平均が後ろ側なら反転）、前方への到達（前方向への射影の最大）、後方への到達（最小の符号反転）を返す。

#### 5.1.3 切断と連結成分

1. 体の溶接済みメッシュを平面ごとに順に二分し、残さない側に中心がある面を消す。
2. 連結成分のうち、種の最近頂点を含む成分と、（脚の衣類では）平均の脚ウェイトが 0.5 以上の成分を残す。他は消す。面が残らなければエラー。
   ただし、種で残した成分から全頂点が 8 mm 以内にある成分（手足の指から離れた島になっている爪、体に付いたばんそうこうなど）は、脚ウェイトに関わらず布にしない（それぞれが別の布の小片になる）。その下の肌で布を持ち上げる量に使う（8.1 の島の扱いと同じ）。
   **体の切り口**（肌が途中までしか無い体）: 範囲の開いた縁のうち、頂点の半分以上がどの平面からも 0.3 mm より遠く、長さが股関節の間の距離以上（腕の衣類では半分以上）の物（脚・腕を一周する体の切り口）ごとに、縁に接する面の中心の平均が縁より下なら、縁の一番低い点 − up × 3 mm に法線 up の上端の平面（下を残す）を、上なら一番高い点 + up × 3 mm に下端の平面（上を残す）を足し（腕の衣類では up の代わりに、縁の中心に近い腕の区間（肩→肘、肘→手首）の向きを使う）、それで切って連結成分を選び直す。足した平面は以後ほかの平面と同じに扱う（上端の帯もそこに付く）。体の切り口が斜めだと、それに沿った衣装の端も斜めになり、角が尖るため。
3. **被覆距離**（体の各頂点、m）: 残った頂点について、その側に効く全平面の符号付き距離の最小値（＝範囲の縁までの距離）。範囲外は −1。
   フェイクサイハイで肌の写しを使わないときは、境目（7.8）より上を範囲外扱いにする（境目までの距離を負にする）。この値は肌の削除（6.5）に使う。
4. ここで範囲の複製を 2 つ作る:
   - **布の素材**: 縁（平面上の境界）以外の穴だけを埋めた物（穴が平面上の縁かどうかは、境界ループの全頂点がいずれかの平面から 0.05 mm 以内かで判定）。
   - **閉じた範囲**: すべての穴を埋めた物（SDF 用）。

#### 5.1.4 親指サックの切り方

足の指の塊（足の指ごとに骨を持つアバターは骨のウェイトの番号、無いアバターは 5.3.3 の 3 と同じく形で分けた塊）のうち、
足の付け根の平面（到達 × 0.55）より前・足首より下で、足の内側（-左右 × lateral を前と上に直交させた向き）への座標の平均が最も大きい塊を親指とする。
足ごとに滑らかな形（8.1.1 と同じ）で切る: 残すのは「付け根より前」と「ほかの指の点より親指の点に近い（2 つの距離の差の半分）」の丸めた積
（丸めの半径は到達 × 4%）。
付け根（口）は、親指と人差し指の**股**が分かれば、股から到達 × 0.04 後ろ（到達 × 0.6 から親指の先 − 到達 × 0.05 までに収める）:
- 隙間: その足の足首より下で、到達 × 0.85 より前の、上を向いた（入力の法線と上の内積 > 0.3）体の頂点を内側への座標で並べ、内側の半分にある
  いちばん広い隙間の真ん中を中心線とする（幅の 3% より狭ければ、指が付いているとして股は無し）。指の塊の平均の中間は、幅の広い親指の縁に乗ることがあるので使わない。
- 股: その中心線を横切る、足首より下の、上を向いた（3 頂点の法線の平均と上の内積 > 0.3）体の三角形の最も前の頂点の到達に対する割合。足の裏の側は指の先まで
  つながった作りが多いので見ない。親指の先から到達 × 0.1 より後ろになければ股と認めない（指の分かれていない足の面の粗さと取り違えない）。
- 股が分からなければ、親指の塊の最も後ろの点を到達 × 0.6〜0.7 に収めた所（形で分けた塊は指が分かれる所より先だけで、骨のウェイトの塊は付け根の奥まで届く。
  Humanoid の Toes の骨も付け根に無いことがあるので使わない）。
塊が 2 つ以上に分かれない足は、指先（到達 × 0.8 より前）の内側への座標の幅の内側 35% と、到達 × 0.7 より前を残す。ただし上の股が分かれば、隙間の中心線で分け、
口を股から到達 × 0.04 後ろ（到達 × 0.6〜0.9）に置く。どちらも足首より下だけを残し（前にある胸なども親指の点の方が近いことがある）、作れない足はその側をすべて切る。形で分けるときは、最も大きい塊の 5% より小さい塊（爪などの離れた部品）を数えない。
縁の持ち上げ（5.3.2）はしない。指先の張り（5.3.3 の 3）は、口の中心から先端までの前半分だけ。

#### 5.1.5 ガーター・レッグラップ

- **ガーター**: 脚ごとに、脚の鎖 s = 帯の位置を中心に、幅（mm。その区間の骨の長さで鎖の長さに直す）の輪を残す（上の平面の足首側と下の平面の股関節側）。
- **レッグラップ**: 脚ごとに、巻き始めと巻き終わりの s の間（両端は脚に直交する平面）で、脚の座標（7.9）の (s, u) から、
  らせん u = ±回数 × (s − 始め) / (終わり − 始め) の中心線までの距離が幅の半分以内の所を残す（滑らかな形で切る、8.1.1）。距離は、
  脚の周りのずれ（回転数）を、点から脚の軸までの半径の弧の長さにし、らせんの傾きで縮めて測る（× 範囲の長さ / √(範囲の長さ² + (回数 × 2πr)²)）。
  交差させるときは逆向きのらせんも残す（同じ面から切るので交差する所は 1 枚）。両端には脚を水平に 1 周するリボンの幅の輪も残し（らせんが途中で切れて終わらない）、らせんは両端の輪の中心線の間だけにする（輪の外へ端が飛び出さない）。切る前に、巻く範囲（両端から鎖で 0.1 の余裕）で、リボンの縁の近くを通る辺
  （両端の形の値の絶対値の小さい方が辺の長さより小さい）のうち、リボンの幅の 90% より長い物を 3 回まで二分する（大きな三角形の頂点の間をリボンがすり抜けて消えない）。
- 付け根の近く: 股の底（体の中心線から股関節の間隔の 5% 以内で、股関節より下・膝より上の、法線が真下から 45° 以内の点のうち最も高い物）を求め、
  帯の上の縁（ガーターは中心 − 幅の半分、レッグラップは股関節側の端）の脚に直交する平面が、股の底より 3 mm 以上下を通る最小の s（0.01 刻み、両脚で大きい方）
  まで、位置を下げる（股をまたいで左右の脚がつながらない）。太ももの内側どうしが付け根まで触れる体では、その間に少し布が残る。
- 共通: 縁の持ち上げ（5.3.2）と下着の上の余裕はしない。肌との隙間は 0.3 mm 以下。部位分け（5.6）はせず全体を 1 つの部位にする（ゴムの帯の部位が
  縞のように交互に出るため）。Unity では影を受けず（receiveShadows オフ）、ウェイトは体のものだけを使う（下の層の服のウェイトは左右の脚が混ざることがある）。
  切った後の塊は、左右の脚にまたがる物のほかはすべて残す。
- 下の層: 「タイツ・靴下の上に付ける」がオンなら、前に作った脚の衣類（タイツ・スパッツ・サイハイ・ニーハイの布の本体）と、アバター自身の脚の服
  （太ももの半ばより下まで届く物。スパッツを除く）を下の層として渡す（実物も靴下の上からリボンを巻く。下に収めようとすると服を突き抜ける）。
  「アバターの靴下・レッグウォーマーの上にも巻く」がオフなら、アバター自身の脚の服は下の層にも上に着る物にも数えない（服を脱がせた状態用）。
  体の頂点ごとの下の層の高さ（4 章）と下着の面からの作り直し（5.7）は使わず、仕上げの後に各頂点から法線の向きに 15 mm まで光線を飛ばし、最後に
  当たった下の層の面の外 offset まで持ち上げる（持ち上げる量は隣と 3 回平均し、各頂点で自分に要る量を下回らない。体の中心線の手前で止める）。
  上に着ている、肌から 8 mm 以内の服の下になる面は最初から作らない。
  体の中心線の手前で止める。上に着ている、肌から 8 mm 以内の服の下になる面は最初から作らない。Unity のウェイトは体のウェイトだけ（下の層の服の
  ウェイトは左右の脚が混ざることがある）。切った後の塊は、左右の脚にまたがる物のほかはすべて残す。
- レッグラップのらせんは、脚の鎖に沿った脚の半径（40 区間の中央値）で回転の進みを決め、どこでも同じ傾きで巻く（太い所はゆっくり回る。等間隔だと
  太ももでリボンが寝て交差が潰れる）。縁の近くの長い辺は、リボンの幅の 90% より長い物を 3 回まで二分する（大きな三角形の頂点の間をリボンがすり抜けて消えない）。
- **リボンの結び目**（ガーターでリボンがオン。仕上げの最後に足す）: 帯の中心の脚の軸から、前から外側へ 35° 回した向きに帯の外面を探し、そこを原点に、
  脚の周り x・軸に沿った y・外面からの高さ z の平らな座標で、リボンの断面（幅 = 帯の幅 × 0.32、厚み 0.6 mm。両端を半径 = 厚みの半分の半円に丸めた平たい形）を
  掃いた閉じた立体を作る: 2 つの羽根（リボンが結び目から外へ出て先で折り返し、帯の側へ戻る。道筋は脚の周りと外向きの面の中のふくらんだしずく形
  （長さ = 帯の幅 × 0.95、ふくらみ = 帯の幅 × 0.32 × 先への割合^0.7。付け根では 0 で、横から穴が見えない）で、リボンの幅（帯の幅 × 0.75）は脚の軸の向き。幅は結び目で 45%、中ほどで最大、先で 77%。左右で少し上下に開く。
  道筋を帯の面の中に置くと、前から輪の穴が見えて線画のようになる）、2 本の垂れ（下へ帯の幅の 1.7 倍と 1.55 倍、外へ少し開き緩い S 字。幅はリボンの
  62% から先へ 15% 広がる）、結び目（くびれた羽根の付け根を縦に巻く短く太い輪。幅はリボンの 32%、厚み 1.4 倍）。
  自分の向きに測った帯の外面（帯の外では、肌 + 付け根での帯の厚さ）の上に置く。部位は帯、陰影は布自身の法線。垂れの頂点には、垂れの番号と
  根元からの割合を付けて出力する（output.json の swing）。

### 5.2 エンベロープ（SDF の外形）

- offset = 肌との隙間 + 布の厚み。
- 細かい格子 fine = max(計算の細かさ, offset × 0.4) mm、粗い格子 coarse = max(fine, 1.6 mm)。
- **全体の外形**: 閉じた範囲を粗い格子で SDF にし、offset だけ外へずらし、ラプラシアン平滑を 3 回かけて面にする。持ち上げ・内部除去の目安にだけ使う。
- **足先の面**（つま先「まとめ」・スパッツと腕でない場合）:
  体を「足首の高さ + (膝の高さ − 足首の高さ) × 0.2」（左右で高い方の足首・低い方の膝）より下で切り、切り口を閉じた物を、細かい格子で SDF にする。
  クロージング半径 r = 足指の間を埋める + 布の厚み として、`SDF を +r ずらす → 面にする → SDF にし直す`。これにラプラシアン平滑 3 回をかけ、
  閾値 offset − r で面にする（−r ずらす形態学的クロージングと offset のずらしを 1 つの閾値にまとめた物。幅約 2r より狭い指の隙間が埋まる。
  クロージングは元の形を含むので、元の SDF との和は要らない。距離の大きいずらしのノードは重いので省く）。足袋型は 5.4.1。
- SDF の帯域幅は `max(3, (r + offset) / 格子 + 3)` ボクセル。

### 5.3 法線方向への押し出し（布の素材の各頂点）

#### 5.3.1 お尻の橋渡しの準備（タイツ・スパッツのみ）

実物のタイツはお尻の割れ目に入り込まず、上を渡る。そのため割れ目を閉じた面を用意する。

- 前方向は左足→左つま先のボーン（無ければ体の前方向）を水平化。
- 半幅 half_w = hip_w × 0.35。
- **股の最下点**: 中心線付近（|横| < leg_len × 2%、|前後| < leg_len × 20%、股関節中点より下で −leg_len × 40% より上、法線·up < −0.5）の頂点の最低の高さ。無ければ −leg_len × 10%。
- 下端 bottom = 股の最下点 − leg_len × 1%、上端 top = +leg_len × 25%、フェード幅 fade = leg_len × 4%。
- **重み** weight(p): 横 `clip((1 − |横|/half_w) / 0.4)` × 下端からのフェード × 上端からのフェード × 後ろ側のフェード `clip(−前後 / fade)`、最後に smoothstep。
  前側（股）は橋渡ししない（渡すと股の下で布が裂けたように見えるため）。
- **後ろへの張り出し**: 高さ方向に leg_len × 0.4% の薄切りごとに、お尻付近の三角形（頂点のどれかが範囲内）の最も後ろの位置を記録する（三角形は角がまたぐ全ての薄切りに数える）。
- **橋渡しの面**: 体をこの範囲（上下左右に fade の余裕）で切り、穴を閉じた物を、格子 max(3 mm, 計算の細かさ)・クロージング半径 40 mm・offset で 5.2 と同じ手順で SDF の面にする。

#### 5.3.2 各頂点の持ち上げ

下着がある頂点の「普段の厚み」worn_usual = 下着の高さが正の頂点の中央値。
下着の上限 worn_cap = 内側に収めるなら無限、股の見た目を優先なら max(4 mm, worn_usual × 2)。

各頂点 v について、体への結び付け（三角形 t・重心 b・最近点 loc・法線 n）から:

1. **関節**: joint = clip(2 × 補間した関節の混ざり, 0, 1)。
2. **下着の高さ** worn = 補間した下着の高さ（溶接済み）。worn_raw として元の値も保持。worn = min(worn, worn_cap)。
3. **お尻の橋渡し**（重み sw > 0 の頂点）: 橋渡しの面の最近点 hit・法線 hn を求め、
   - 割れ目の深さ cleft = −(loc − hit)·hn − offset。
   - loc から hit 方向へ 1 mm 進んだ点から hit まで光線を飛ばし、体に当たれば対象外（太ももの横のしわで、向こうの橋を拾わない）。
   - sw に `clip((方向·up + 0.8) / 0.5)` を掛ける（股から真下へ向かう所は 0。下で布が折れないようにフェード）。
   - cleft > 0.2 mm・遮られない・sw > 0 なら橋渡しの対象。下着の高さを、割れ目の上で「max(worn_usual + 1 mm, worn − cleft)」へ sw の割合で近づける（下着の高さは法線方向で測るため、割れ目をまたいで大きく出るのを抑える）。
4. 下着がある（worn > 0）なら、下着が自分のウェイトで動く分の余裕として worn += 2.5 mm × clip(worn / 1 mm, 0, 1)。
5. **裾の余裕**: 縁（その側に効く平面）までの距離 d に対し、f = clip(1 − d / 25 mm)、hem = 2.5 mm × smoothstep(f)（実物のゴムの帯のように縁の近くを浮かせる。縁は体の三角形の途中を切るのでウェイトが補間になり、腰を動かすと肌から離れやすいため）。腕の衣類で手を切る滑らかな形（指の付け根・親指の穴、8.1.1）の縁は数えない（手は小さく、25 mm の帯で口が釣り鐘のように開く）。
6. 持ち上げ量 lift = offset + worn + max(関節の余裕 × joint, hem)。
7. **細い溝の制限**: loc から n 方向に 0.3 mm 進んだ点から n 方向に lift × 2 まで光線を飛ばし、体に当たれば half = (当たった距離 + 0.3 mm) / 2（向かいの肌までの半分）。
   さらに、股関節より下で、体の中心線から 0.5 mm 以上離れ、法線が中心線を向く（中心向きの成分 > 0.05）頂点は、half = min(half, |中心線までの距離| / 中心向き成分 × 0.9)（中心線を越えない）。
   half が決まれば half = max(0.1 mm, half, 下着の下限, 島の下限)、lift = min(lift, half)。この制限は後でもう一度かける。
   下着の下限は、内側に収める かつ worn > 0 なら offset + worn。ただし股（股関節より下で、体の中心線から 40 mm 以内）で下着の下限が half より大きい所では 0（下着はくぼみをまたいでいるので、向かい合う壁をそれぞれ下着の高さまで持ち上げると左右の衣装が交差して折れ目になり、後のならしでも取れない）。
8. **天井（上に着た物）**: 結び付けの三角形の頂点（重心 > 1e-4）の天井の最小値があれば、cap = max(0.3 mm, 天井 − 0.4 mm)、lift = min(lift, cap)。この制限も後でもう一度かける。
9. 位置 q = loc + n × lift。
10. **橋渡しの対象なら**: 余裕 room = lift − offset。下着があれば、下着の面（loc + n × worn_raw）の橋渡しの面からの高さ（ただし worn_usual × 1.5 まで）+ 2.5 mm と比べて大きい方にする。
    q を「hit + hn × room」へ sw の割合で近づける（向かい合う壁が法線方向に持ち上がって交差しないよう、橋渡しの面から測る）。sw > 0.5 の頂点は「橋渡し済み」とし、その room を記録する。
11. **エンベロープ**（橋渡し済みでない頂点）: 全体の外形の最近点からの沈み depth を測る。
    - depth > 6 mm: 体の内部（内側の形状）とみなし「深い」印を付ける。
    - 0.2 mm < depth ≤ 3 mm: 外形の上へ持ち上げる（へそ・浅い溝を埋める）。それより深い溝は追う（体の点から大きく離すと関節で肌からずれるため）。
12. 各頂点に**元の体の点** loc を記録し、「体に沿う頂点」の印を付ける。
    **基準の高さ（フレーム）**として（肌の点, 法線, 下限の高さ）を記録する: 橋渡し済みなら（橋渡しの面を offset 下げた点, hn, offset + room）、
    それ以外は（loc, n, min(lift, 基準 + 縁の浮かせ)。基準は内側に収めるなら offset + worn、でなければ offset）。後の修正は各頂点をこの下限より下げない。
    （縁の浮かせを下限に含めないと、しわ取りが広がりの届いた縁の頂点だけ浮かせを消し、届かなかった頂点に残して、縁が鋸の歯に
    なる）

#### 5.3.3 押し出し後の整え

1. 橋渡し済みの頂点を 8 回、隣の重心から橋渡しの面へ最近点で落とし、その法線方向に room だけ離した位置へ移す（割れ目の壁が順序を崩して面が折れるのを直す）。
2. **溝の埋め**（外向きだけの平滑化）: 10 回、各頂点が隣の平均より法線方向に下にあれば、その差の半分だけ法線方向へ出す（下げることはない）。
   最終的な持ち上げは開始位置から法線方向に 0〜4 mm に制限する（体の点から離れすぎない）。橋渡し済みの頂点は元に戻す。
3. **指先を張る**（指を包む手袋（5 本指・オペラ・絵描き用）の指先と、足の指ごとに骨を持つアバターの 5 本指の足の指。切り口の縁の頂点は動かさない。骨の無いアバターの足の指は、付け根で深くつながっていて形だけでは指ごとに分けられないので行わない）: 伸びた布は膜のように、爪の付け根や両脇の溝・長い爪の先の下に入り込まず、出っ張りの間に張る。
   - 区間: 手は、中指の付け根から先の関節までの長さ L で、付け根から 0.55 L より先。指の番号は、指をまたぐ向き（人差し指 − 中指の付け根の、中指の向きに直交する成分）の位置を指の間隔で割って丸めた物。親指は中間の関節より先で、親指の軸から親指の区間長の 1.3 倍以内（長さの 3 倍まで）の、ほかの指でない所。
   - 同じ番号で辺がつながる塊（指 1 本）ごとに、頂点の凸包を作る（近くの爪の島（5.1.3）の点を offset だけ 6 方向に広げた物も入れる）。各頂点を、法線方向の光線が凸包に当たる所まで持ち上げる（15 mm まで）。
   - 10 回、隣の平均と半分ずつ混ぜて角を丸める（元の体の点から法線方向に offset より内へは入れない）。最後に、凸包の面より offset/2 を超えて内に入った頂点を凸包の面へ戻す。
   - 爪の島の各点が、最も近い布の面の内側に offset × 0.75 以上入るまで、その面の頂点を面の法線の向きへ押し出す（4 回まで）。
   - 足の指の骨の無いアバターの 5 本指: 足ごとに、足首から前への到達の割合 r（0.6 から 0.95 まで 0.025 刻み）より前で足首より下の布の頂点を辺のつながりで塊（8 頂点以上）に分け、塊がちょうど 5 つになる最小の r の塊を指ごとに張る（5 つにならない足は張らない）。
   - 足の指: Unity が、体の各頂点でウェイトの半分より多くを持つ足の指（左右の Toes の子ごとの枝）の番号を渡し（job.json の toeDigits。無ければ書かない）、布の各頂点の元の体の点で重心の最も大きい角の番号ごとに張る（持ち上げは 6 mm まで）。上に履いた靴下などの天井（5.3.2 の 8）は、この後も効く。
   - 張った頂点は、後のくしゃくしゃのならし・こぶの引き下げ・細い溝の制限から外す（張った面は爪の下の肌と向きが違い、元へ戻されるため）。出力の法線も、張った指先では体の法線でなく布自身の法線を使う（体の法線は爪の段を写す）。
4. 細い溝と天井の制限をもう一度かける（橋渡し済みと、細い溝の制限は張った指先も除く）。
5. 全頂点が「深い」面を消し、孤立頂点を消す。

### 5.4 つま先（まとめ）

5.2 の足先の面がある場合:

1. **つま先の区域**（足ごと）: 布の素材の点で foot_frame を求め、足首 + 前方向 × (前方への到達 × 0.55) に平面を置く（指が分かれ始める手前）。
   区域の上限: 平面より前にあるその側の点の高さ（足首基準）を昇順に並べ、前方への到達 × 15% より大きい隙間の手前（無ければ最大）に、到達 × 0.5 の余裕を足した高さ。
   次の塊の手前（隙間 × 0.2 を引いた高さ）は越えない。0 未満なら 0。区域 = その側・足首基準の高さが上限以下・平面より前。
2. 目標の三角形数 = max(200, 区域内の布の三角形数 × 足先のポリゴン密度)。
3. 布を区域の平面で切り、区域内を消す。足先の面から、区域の周り（平面の手前、足首〜平面の距離 × 20% の余裕）の面だけを取り出し、同じ平面で切って区域内だけを残す。
4. 足先の面を目標の三角形数まで縮約（Collapse）して、布に加える（これらの頂点は「体に沿わない」頂点。元の体の点は自分の位置）。
5. 区域ごとに、平面上（0.05 mm 以内）にある体に沿う頂点の境界ループと、体に沿わない頂点の境界ループを取り出す
   （連鎖が小さな隙間で切れていれば、最長辺の 3 倍以内なら閉じる）。両ループを平面上の角度で並べ、角度の小さい方から順に三角形でつなぐ（縫い合わせ）。
   ループが取れなければ警告して縫わない。面の向きを揃える。
6. 縫い目の周り（平面から足首〜平面の距離 × 12% 以内、縁でない頂点）を 6 回、隣の平均と半分ずつ混ぜて平滑化する（SDF の面と体に沿う面の高さの違いを消す）。
6.5 **つま先を張る**: 区域の頂点（縁を除く）を、足ごとの凸包の最も近い面まで持ち上げる（6 mm まで。法線の向きだと、指の間の溝の頂点は隣の指の方へ横にずれるだけで溝が埋まらない）。続けて 5.3.3 の 3 と同じく角を丸め、凸包へ戻す。実物のストッキングのように、5 本の指をまとめて包む 1 つの面にする（指の間の溝・爪の段を写さない）。出力の法線は、区域では布自身の法線を使う。その後、指から離れた島の爪を覆う（5.3.3 の 3）。
7. 体に沿わない頂点にも天井（5.3.2 の 8）を適用する。押し込んだ頂点があれば、5 回「隣の平均と半分混ぜる → 天井を再適用」を繰り返す（指先で法線が急に回るので押し込みでしわになるのを防ぐ）。

5 本指・スパッツ・腕の衣類・親指サックでは足先も体に沿わせる（この節を行わない）。

#### 5.4.1 足袋型

足の指の塊（5.1.4 と同じ）が 2 つ以上に分かれる足だけ、5.2 の足先の面を作る前に、足先の体の点のうち「付け根の平面より前・足首より下で、最も近い指の点が親指以外の物」を、
付け根の平面の上の親指と人差し指の中ほどを通る上向きの軸の周りに、外側へ 25° × 割合だけ回す（割合は付け根の平面から親指の塊の最も後ろ（到達 × 0.7〜0.85 に収める。急に変わると外側の指の付け根の面が後ろへ折れ返る）までで 0 から 1 へなめらかに。
親指を内側へ開くと、足を揃えたアバターで両足の親指が近づき、クロージングでつながる）。開いた形で SDF の面を作ってから、面の頂点を元の向きへ戻す
（開く側かは、開いた後の指の点で見分ける。開いた後は親指と人差し指の間が広いので確か。割合は戻した位置で決まるので 4 回の反復で求める）。
6.5 の凸包は、足ごとに親指とほかの 4 本で分ける。指の塊が分かれない足は「まとめ」と同じ。

### 5.5 崩れの修正

#### 5.5.1 しわ取り（relax_crumples）

- **しわの面**: 全頂点がフレームを持つ面のうち、面の法線と「各頂点のフレームの法線の和」の内積が 0.5 未満（肌から 60 度以上ずれた面。折り返し・溝で立った面）。
- 最大 24 回: しわの面の頂点を対象に加え、さらに毎回 1 リング広げる。対象の各頂点を、自分の肌の点から法線方向に「隣の高さの平均」の位置へ戻す。
  後半 12 回は高さを下限へ向けて 0.8 倍に縮める（`下限 + (min(平均, 今の高さ) − 下限) × 0.8`）。下限 = max(0.5 mm, フレームの下限)。しわが無くなれば終わる。
- 足先の置き換えの後に行う（体自身の指が指の間で縮れているため）。その後、細い溝と天井の制限をもう一度かける。

#### 5.5.2 高品質の細分化（refine）

- 余地 = 上限 × 0.85 − 今の三角形数 − 縁の辺の数 × 4（縁は後で厚みが付くため。2 層式は上限を半分にする）。
- 長い辺から順に最大 余地 / 2 本を 1 回ずつ分割する（グリッド埋め、平滑 0.3）。5 角形以上は三角形化する。
- 新しい頂点は、両隣がともに体に沿う頂点なら、隣の元の体の点の平均を体に結び付け直し、その点から法線方向に offset 以上離す。そうでなければ体に沿わない頂点。
- 分割後、体に沿う全頂点のフレームを元の体の点から作り直し（下着の高さも 5.3.2 と同じ規則で）、しわ取りをもう一度行う。

#### 5.5.3 こぶ取り（flatten_bulges）

最大 6 回: フレームを持つ頂点のうち、隣（3 つ以上）の高さの中央値より 3 mm を超えて高い頂点を、`max(中央値 + 0.75 mm, フレームの下限)` の高さへ下げる。

#### 5.5.4 お尻の外形の制限（hold_in_seat）

お尻の重みが閾値より大きい頂点について、その高さの薄切りの「後ろへの張り出し」より、`offset + worn_usual` を超えて後ろに出ていれば、前へ戻す
（ただしフレームの下限を割る場合は動かさない）。ここでは閾値 0、5.8 の後にもう一度閾値 0.5 で行う（割れ目の底が横から見てひれのように出るのを防ぐ）。

#### 5.5.5 たるみ（add_wrinkles）

量 a（0〜1）> 0 のとき、フレームを持つ頂点の元の体の点で脚の座標 (s, u)（7.9）を求め:

- 足首: s が 1.75〜2.0（両端 0.06 でフェード）。
- 膝裏: s が 0.9〜1.1（両端 0.05 でフェード）× 後ろ側（|u − 0.5| < 0.2、端 0.08 でフェード）。
- 重み w = 両者の大きい方。峰 = 0.5 + 0.5 sin(2π s / 0.035 + 0.6 sin(2π · 3u))。
- 頂点を肌の法線方向（外向きだけ）に `1 mm × a × w × 峰` 動かす。

#### 5.5.6 小さな穴の補修

縁（元の体の点がいずれかの平面から 0.3 mm 以内）でない境界辺が 1〜24 本なら、穴を埋める。補修後も残る縁でない境界辺は「穴」として品質検査に回す。

### 5.6 部位分け（実物の構造）

実物のタイツで編み方が違う部分を、平面で布を切り分けて面ごとに部位番号を付ける（境目はくっきりした線になる）。
寸法は leg_len・hip_w に対する比率なので体格によらない。部位の判定は面の中心で行い、後に書く物ほど優先する（股の部位が最優先）。

| 部位 | 番号 | 位置・大きさ |
|---|---|---|
| 脚 | 0 | 既定 |
| パンティ部 | 1 | （タイツ、パンティ部オン）ランガードの平面より股関節側 |
| 帯 | 2 | ウエストバンド: 「下を残す」平面（タイツ・スパッツのウエスト、ソックスの上端、腕の衣類の上端）から leg_len × 3.5% 以内（ウエストバンドオン）。ランガード: 脚の鎖 s = 0.2 の平面から下へ leg_len × 3% の幅（タイツ、ランガードオン） |
| 補強 | 3 | 足首より下のつま先・かかと（タイツ・ソックス） |
| 上部 | 4 | フェイクサイハイの境目より上の脚（脚の部位だった所だけ） |
| ソックスの帯 | 5 | フェイクサイハイの境目から下へ leg_len × 3.5%（境目の帯オン） |
| 縫い目 | 6 | 中心の縫い目（タイツ） |
| ひしマチ | 7 | 股の菱形（タイツ） |

切る順と形:

1. 帯の平面、ランガードの平面（パンティ部かランガードがオンなら s = 0.2 で切り、ランガードがオンなら幅の下端でも切る）、フェイクサイハイの境目と帯の下端。
2. **股の部位**（タイツで、中心の縫い目かひしマチがあるとき）:
   - 股の点: 布の頂点のうち |横| < leg_len × 3%、|前後| < leg_len × 25%、股関節中点より下の物で最も低い点（前方向は体の前方向）。無ければ股の部位なし。
   - ひしマチ: 半幅 a = hip_w × 0.2 × 大きさ、前後の半長 b = a × 縦横比。中心 = 股の点の高さ・前後位置の中心線上。
     4 枚の平面（点: 中心 + 横 × ±a、法線: 横 × (±1/a) + 前 × (±1/b) を正規化）の内側全部が菱形。高さが股の点 + 1.5a より下かつ |横| < hip_w × 0.6 の所だけで切る・判定する。
   - 中心の縫い目: 幅 w = leg_len × 0.6%。前（前後位置が股の点より前）・後ろ・両方を選べる。|横| ≤ w/2 かつ 高さ ≥ 股の点 − leg_len × 5%。|横| < hip_w × 0.6 の所だけで切る。
3. **足**（タイツ・ソックスで、つま先かかかとの補強があるとき）: 足ごとに foot_frame を求め、足首から leg_len × 25% 以内を足首の高さの水平面で切る（補強の上端を線にする）。
   - つま先の補強: 点 toe = 足首 + 前 × 前方への到達 × 0.70。「まっすぐ」はその点・法線 前 の平面より前。「包む形」はさらに、
     toe − 前 × 到達 × 0.12 + 外側 × 到達 × 0.12（左右両側）に、法線 `前 cos40° + 横 (±sin40°)` の平面を加え、どれかの前にあれば補強（指の両脇へ回り込むトウキャップ形）。
   - かかと「カップ」: 足裏の高さ sole（その側の全頂点の足首基準の最低高さ、負）として、上端 = 足首 + up × sole × 0.35 の水平面より下、
     前端 = 後端（足首 − 前 × 後方への到達）から前へ (前方 + 後方の到達) × 0.30 の平面より後ろ、
     角 = 前端の位置で上端の高さの点から `(up + 前)` 方向に半径 r = −sole × 0.3 だけ戻した点を通る法線 `(up + 前)` の平面より後ろ。3 つすべてを満たす所（U 字の袋）。
   - かかと「Y ヒール」: 点 足首 − 前 × 後方への到達 × 0.10、法線 `前 + 0.8 up` の平面より後ろ（足首の後ろから足裏へ斜めの線）。
   - つま先の補強が「ヌード」なら作らない。
4. 面ごとに部位を決める（足首より下で補強の条件 → 補強、それ以外でランガード → 帯／パンティ部、帯の平面 → 帯、フェイクサイハイの境目 → 上部／ソックスの帯（補強は除く）、股の部位 → 縫い目／ひしマチ）。

### 5.7 下着の面からの作り直し（snap_to_under）

下着がある場合（下着の面が空でないとき）、下着の上の頂点を下着の面に合わせて置き直し、下着と一緒に動くようにする（Unity でそのウェイトを使う。6.2）。

1. 各頂点の元の体の点で下着の高さ worn（溶接済み）を補間し、worn > 0 の頂点だけ扱う。
2. 「既に十分持ち上がっている」= 肌からの高さ > worn + offset + 2.5 mm + 2 mm（お尻の橋渡しや股の間で持ち上がった所）。この頂点は位置を変えず、下着との対応だけ記録する。
3. 推定点 loc + n × worn から worn + 3 mm 以内で下着の面の最近点 hit を探す。hit の法線（肌の法線側へ向けた物）と肌の法線の内積が 0.6 未満、
   または hit が肌の法線の線から横に worn + 2 mm を超えて離れていれば対象外。
4. 対象の頂点は、必要な高さ `(hit − loc)·n + offset + 2.5 mm` を記録し、今の高さが足りなければ法線方向へ持ち上げる（横へは動かさない。股の間で法線が回る所で面が折れるため。下げない）。
   下着の三角形番号と重心座標を記録する。
5. 最大 10 回: 面の法線が処理前の向きと 60 度以上ずれた面の頂点とその隣を、隣の平均と半分ずつ混ぜて平滑化する（縁は除く）。
   ただし必要な高さより下がった頂点は法線方向に戻す。必要な高さを記録していない頂点も、肌からの高さが offset より下がったら法線方向に戻す（股の付け根の溝で、平均へ寄せると肌の下へ引かれ、肌が布の外に出ていた）。

### 5.7.1 体の三角形の中を覆う

脚の衣類で、範囲の縁から 2 mm より内の体の三角形のうち、足首より上の物について、三角形の中の 9 点（重心、辺の中点、重心と各頂点・各辺の中点の中ほど）のうち、布の面の外へ突き抜けた点を、面の内側 offset × 0.2 まで入れる。点に最も近い布の面が、その点の近く（面の頂点の元の体の点の平均が、三角形の最長辺の 2 倍以内）の肌から作った面なら、足りない分だけ面の頂点を面の法線の向きへ押し出し、押し出す量を隣の頂点へ半分ずつ 2 段まで分ける（4 回まで。1 つの面だけが飛び出して尖らないように）。布の頂点は肌の外でも、橋渡しなどで頂点が横にずれると、肌の三角形の真ん中が布の面を突き抜けるため。足先と腕の衣類では行わない（指の間では布どうしが近く、どの面を押しても隣の指の布とぶつかる）。

### 5.8 折れのならし（smooth_folds）

- 各頂点の下限: 5.3.2 のフレーム（無ければ offset）。5.7 の必要な高さの方が高ければそれを使う。
- **折れの辺**: 布が 60 度を超えて折れ、かつ下の肌（両端の肌の法線のなす角）より 35 度以上多く折れている辺。
- 最大 10 回: 折れの辺の頂点とその隣（縁でなく、フレームを持ち、肌の点の法線の線から横に 2 mm 以内の頂点だけ）を、隣の平均と半分ずつ混ぜる。
  下限より下がれば法線方向に戻す。最初の肌からの距離より 2 mm を超えて離れた頂点は、その回の移動を取り消す。
- その後、5.5.4 の制限を閾値 0.5 でもう一度かける。

### 5.9 縁の厚み付けと出力

#### 5.9.1 厚み付け

布（外側の面）に、内側へ布の厚みだけの Solidify を「縁だけ」かける（内側の面は体で隠れて見えないので作らない）。
「均一な厚み」は使わない（鋭い角で厚みが際限なく伸びて尖るため）。高品質の法線を使い、全面をスムーズシェードにする。

#### 5.9.2 頂点の体への結び付け

- 体に沿う頂点（厚みで増えた頂点も、元の頂点の情報を受け継ぐ）: 元の体の点を体に結び付ける（その点のウェイトを正確に受け継ぐ）。
- 体に沿わない頂点（足先の面）: 自分の位置から布の法線の逆向きに 15 mm 以内の、まっすぐ下の体の点に結び付ける（当たらなければ最近点）。最近点だと、指の間を渡る所で隣り合う指の間を飛び、写しの肌の色（爪の色、指の股の陰）が引き伸ばされ、ウェイトも混ざるため。

#### 5.9.3 体の UV（肌の写し用）

面ごとに、その角の結び付け先の点の平均を体に結び付けた三角形（参照三角形）を決め、面の全角の UV を参照三角形の UV から求める
（角の結び付け先が参照三角形と同じなら重心座標、違えば参照三角形の平面での重心座標を切り詰めずに外挿）。
1 つの面が体の UV の島をまたがないため、継ぎ目で乱れない。角ごとの UV が違えば、出力で頂点が分かれる。

#### 5.9.4 脚の座標

7.9 の (s, u) を各頂点の元の体の点で求める（前方向は foot_frame の前方向の左右平均。無ければ体の前方向）。
面の角がすべて同じ脚で、u の幅が 0.5 を超える（脚の前を 1→0 でまたぐ）面では、u − 脚の基準（左 0、右 2）が 0.5 未満の角に 1 を足して連続させる（テクスチャは繰り返し）。

#### 5.9.5 法線

各出力頂点の法線は、肌から offset + 1.5 mm 以内なら、体の滑らかな法線（面の法線と同じ半球に向けた物）と混ぜる。
混ぜる割合 w = clip((offset + 1.5 mm − 肌からの距離) / 1.5 mm)。ただし体の法線との内積が 0.3 以下なら混ぜない。
（体に沿う所は縮約・細分化したメッシュ自身の法線より体の法線の方がきれい。指の間を橋渡しする所はメッシュの法線を使う。）

#### 5.9.6 出力頂点と書き出す物

出力頂点 = （頂点, 角の法線（1e−3 で丸め）, 体の UV（1e−5）, 脚の座標（1e−5））の組の一意な物。

| 書き出す物 | 単位 |
|---|---|
| 位置・法線・体の UV | 出力頂点ごと |
| 結び付け（体の三角形番号・重心座標） | 出力頂点ごと |
| 三角形 | 出力の三角形 |
| 被覆距離（5.1.3） | 体の元の頂点ごと（溶接を戻して） |
| 伸びのマスク（7.4） | 出力頂点ごと |
| 部位番号 | 出力三角形ごと |
| 脚の座標 (s, u) | 出力頂点ごと |
| 下着の三角形番号・重心座標（5.7、無ければ −1） | 出力頂点ごと |
| 結果の JSON | 成否、エラー、頂点数、三角形数、体の頂点数、覆った体の頂点数、品質検査 |

#### 5.9.7 品質検査（修正はしない。ログと JSON に出す）

| 項目 | 基準 |
|---|---|
| 尖り | 隣り合う面が 100 度を超えて折れる辺（両端の体の法線の内積が 0.5 未満の所、つまり体自体がそう折れている所は除く） |
| 浮きすぎ | 結び付け先から `offset + min(worn_cap, 下着の高さの最大) + 2.5 mm + max(関節の余裕, 2.5 mm) + 13 mm` を超えて離れた頂点（溝の埋め 4 mm・外形 3 mm・橋渡し等 6 mm の合計の余裕） |
| 細い三角形 | 最小角 2 度未満 かつ 最長辺が辺の中央値の 3 倍超 |
| 穴 | 5.5.6 の縁でない境界辺 |
| こぶ | 肌からの距離が隣の中央値より 4 mm を超えて大きい頂点 |
| ぎざぎざ | 30 度を超えて折れ、かつ下の肌（結び付けの三角形の面法線の角度）より 35 度以上多く折れる辺 |

それぞれ件数と、20 mm の升目（股関節中点基準の横・上・前、mm）で多い順に上位 5 か所を出す。

## 6. Unity 側の組み立て

### 6.1 Blender の実行

- `blender -b --factory-startup --python <生成スクリプト> -- <job.json>` を非同期で起動し、出力を逐次ログに取る（`[LW] ` で始まる行は進捗として表示）。
- 経過時間が打ち切り時間（2.1）を超えたらプロセスを止め、時間切れとして失敗させる。
- Blender の場所: 保存された場所、なければ Windows のインストール済みプログラムの記録（アンインストール情報）のうち版の新しい物、なければ Program Files の `Blender Foundation\Blender*\blender.exe` のうち版の新しい物。

### 6.2 ボーンウェイト

出力頂点ごとに、結び付け先の体の三角形の 3 頂点のウェイトを重心座標で混ぜる（重心が 0 以下の角は除く）。その後、下着の上では下着のウェイトへ寄せる:

1. **下着の縁付近**（衣装を考慮するモードで下着がある場合）: 量 f = clamp01(結び付け先で補間した covered（4.2）)。f > 0 の頂点は、
   体の肌の点（現在の姿勢）とその法線で 4.6 の下着のウェイトを求める。
2. **下着の面から作った頂点**（5.7）: 下着の三角形の 3 頂点のウェイト（4.4）を重心座標で混ぜた物を、量 1 で使う（不明なボーンがあれば使わない）。
3. 混ぜ方: `体のウェイト × (1 − f) + 下着のウェイト × f`。
4. 大きい順に 4 本を残して合計 1 に正規化する。全部 0 ならボーン 0 に 1。

バインドポーズは体の物をそのまま使い、ボーン一覧も体と同じ順にする（複製したアーマチュアの同名ボーンへ差し替える）。
これで布は下の肌と全く同じように変形する（三角形の内側に頂点を置いて補間すると、ローポリの体ほど大きくずれるため、布の頂点は体の頂点の上に置く設計）。

**足の指の骨のウェイトをならす**（つま先をまとめて包む種類で、足の指ごとに骨を持つアバター）: 足の指の骨（左右の Toes の子の枝）のウェイトを持つ布の頂点と、その 2 周外のウェイトを、布の上で隣の頂点の平均と半分ずつ混ぜる（4 回。同じ位置の頂点は毎回そろえる）。指ごとに違う角度に曲げたとき、まとめた面が指ごとに裂けないように、指の間を渡る布を両隣の指の中間で動かす。回数を多くすると強く曲げた指に布が付いていかず、指と指の間だけに絞ると境目で小さな三角形が裏返る。

### 6.3 シェイプキーの同期

体の各シェイプキーの各フレームについて、位置と法線の変位を結び付けで補間して布に加える。どの頂点も変位が 0（二乗で 1e−14 以下）なら加えない。
加えたシェイプキーは、体の現在の値を写し、Modular Avatar があれば MA Blendshape Sync（体の同名キーへ）で以後も同期する。
シュリンク系を 0 にした状態で生成するので、布はシュリンク前の肌の形に合う。

### 6.4 肌の写し（UsesSkinLining）

半透明の布の下の肌を削除し、代わりに布と同じ形の肌を布の内側に描く。布と同じウェイト・シェイプキーで動くので、どの姿勢でも肌が布から出ない。

- 布のメッシュの複製（同じ頂点・ウェイト・シェイプキー）に、5.9.3 の体の UV を入れる。
- 三角形のうち、次を満たす物だけを残す:
  - 部位のマテリアルが半透明（描画キュー 2450 以上）である（不透明な部位は肌を隠すので不要。フェイクサイハイのソックス部など）。
  - 「下着の上」でない: 頂点が下着の面から作られた物、または結び付け先の三角形の角（重心 > 1e−4）のどれかが core（4.2）なら下着の上。
    下着の下の肌は残して下着を透かして見せるため、写しを作らない。ただし「引っ張りで透ける」不透明の布では下着も隠すので、この除外をしない。
  - 前に作った親指サックの下でない: 体の頂点のうち、今の姿勢の法線の向きに 4 mm 以内で親指サック（作った衣装のうち名前が ToeCaps_ の物）の面に
    当たる物を「サックの下」とし、三角形の 3 頂点とも、結び付け先の角（重心 > 1e−4）がすべてサックの下なら写しを作らない（写しは布の面にあり、
    下のサックを隠すため。縁にかかる三角形は残すので肌は出ない）。親指サック自身には行わない。
- 残した三角形を、最初の頂点の結び付け先の体の三角形が属する**体のサブメッシュ**ごとにまとめ、そのサブメッシュのマテリアルの複製で描く。
- **足の指先は単色で描く**: 足先の布の形は体の指と 1 対 1 に対応しない（指の間を埋める・指に沿わせる）ので、体の UV を割り当てると
  爪のペディキュアなどの模様が伸び、指を曲げるとさらに崩れる。体の頂点のうち、足の指の付け根（Toes の骨）より前（足首から付け根への
  向きを、足首から膝への向きに垂直にした向き）で、付け根から「足首から付け根までの長さ」の 1.5 倍以内の物を指先とする（各頂点は、付け根が
  近いほうの足だけで調べる）。結び付け先の角（重心 > 1e−4）がすべて指先の頂点を指先の頂点とし、3 頂点のうち 2 つ以上が指先の三角形は、
  同じ体のサブメッシュでも別のサブメッシュにまとめ、メインテクスチャを外して色を脚の肌の平均色（裏地の「肌から取る」と同じ推定）にした
  マテリアルの複製で描く。Toes の骨が無いアバターでは行わない。
- 肌のマテリアルの複製: シェーダー名に Outline を含めば Outline 無しの版に替える（lilToon の場合を含む。描画キューは保つ）。`_OutlineWidth`・`_Outline_Width` を 0 にする。
  Offset Factor・Units を +1 にする（布と同じ深さにあるので、写しの方を奥へずらす。布を手前に出すと上に履いた靴下より前に出てしまうため）。
  `_AlphaMaskMode` を 0 にする（体のマテリアルが衣装の下の肌をアルファマスクで隠していても、写しには肌を描く）。
- 体のマテリアルが空のスロットは、別のスロットの写しのマテリアルで描く。全部空なら写しを作らず、半透明の布では肌も削除しない。

### 6.5 肌の削除（AAO Remove Mesh By Box）

条件: 「肌を削除する」（2.2）かつ AAO がある。

1. **削除の対象**: 体の頂点のうち被覆距離（5.1.3）≥ 端からの余裕の物。さらに、対象の頂点を含む三角形で、3 頂点の被覆距離がすべて余裕の 1/4 以上なら、3 頂点とも対象にする
   （縁の帯から奥へ伸びる細長い三角形が、関節を曲げたときにとげとして出るのを防ぐ）。
2. **下着の下を残す**: 布が下着の上で透ける（不透明でない、またはフェイクサイハイで上部が透ける）かつ 肌の写しを使う場合は、present（4.2）の頂点を対象から外す（下着の下は写しを作らないので肌を残す）。
   このとき、6.6 の下着の下の肌の追従を付ける。
3. **箱の当てはめ**（体のレンダラーのローカル空間。位置は現在の姿勢・シェイプキーでスキニングした物）:
   - 骨盤: 股関節中点より上の対象の頂点を、up 方向に 10 枚に薄切りする（箱の向き: 軸 up、横 lateral）。
   - 左右の脚: 股関節中点より下でその側の対象の頂点を、鎖 股関節→膝→足首（＋足首より下の点の前方向の平均で、最も前にある対象の点）の最も近い区間に振り分け、区間ごとに区間方向へ 10 枚に薄切りする。
   - 各薄切り: 中の点（3 個以上）の軸に沿った箱（±1e−5 の余裕）を作る。残す頂点が箱の内側にあれば、薄切りを半分に分けてやり直す（最大 3 段）。それでも当たれば捨てる。
   - **補い**: 3 頂点とも対象なのに、まだ全頂点が箱に入っていない三角形を、重心の 2 cm 升目ごとにまとめ、升目ごとにローカル軸に沿った箱を作る。残す頂点が入るなら三角形ごとの箱にし、それでも入るなら諦める。
   - AAO は「三角形の全頂点がどれかの箱の中」の三角形を削除する。
4. **下着の削除**（不透明な布のとき、上に重ねた各下着）: 下着の各頂点の被覆距離を、ワールドで 2 cm 以内の最も近い体の頂点から取り、同じ手順で下着のレンダラーに箱を付ける
   （不透明なら下着は見えず、下着のウェイトで布を突き抜けることもあるため）。半透明なら下着は残す。

5. **持ち主の印**: 削除の部品を付けたオブジェクトに、持ち主の衣装のオブジェクトとその部品を指す印（RemovalOwner。ビルドに入らない）を
   付ける。衣装のオブジェクトには、加えた削除の部品と、0 にした縮めるシェイプキーの名前と元の値の覚え書き（GarmentParts。ビルドに入らない）を付ける。
   - ビルドの最初の段階（NDMF の Resolving。AAO が削除する前）で、持ち主の衣装が無い、または自身か親が EditorOnly の印について、
     その削除の部品を外す。非表示なだけの衣装は外さない（メニューで後から表示する衣装の下の肌も消すため）。印はどれもビルドから除く。
   - ウィンドウの「外す」: その衣装を指す印と削除の部品を消し、覚え書きのシェイプキーを元の値に戻し（同じ体の同じシェイプを、残るほかの
     衣装の覚え書きも 0 にしていれば戻さない）、衣装のオブジェクトを消す。1 回の Undo で戻る。
   - 「片付ける」: 持ち主の衣装が無い印と、その削除の部品を消す。

### 6.6 下着の下の肌の追従（SkinFollow）

半透明の布で下着の下に残した肌は、下着と違うウェイトで動くと布の外へ出る。そこで core（4.2）の体の頂点に下着のウェイトを与える。

- 対象: core の頂点（present の外側の輪は対象外。輪まで引っ張ると隣の肌との間が裂けるため）。
- 各頂点の現在の姿勢の位置と法線で 4.6 の下着のウェイトを求め、上位 4 本を正規化する。見つからなければ自分のウェイトのまま。
- 衣装オブジェクトに SkinFollow（体のレンダラー、頂点番号、本数、ボーン番号、ウェイト）を付ける。アバターのメッシュ自体は変えない。
- **ビルド時**（NDMF プラグイン、Transforming フェーズ。AAO の最適化より前）: 体のメッシュを複製して、対象の頂点のウェイトだけを差し替え、SkinFollow を消す。
- 編集中は NDMF のプレビューで同じ差し替えを表示する。

### 6.6.1 リボンの垂れの揺れ物（SwingTails）

垂れごとに、垂れの頂点の今の位置から根元（割合 0）と先（割合 1）を求め、その間に 3 つの骨を連ねて、根元の頂点で最も重い骨（太ももの骨の写し）の
下に置く。垂れの頂点は割合で隣り合う 2 つの骨に配り、骨とバインドポーズをメッシュに足す。根元の骨に VRCPhysBone を付ける（型は名前で探す。
VRChat SDK が無ければ警告だけ。pull 0.2、spring 0.3、stiffness 0.1、gravity 0.3）。

### 6.7 アバターへの追加

1. 衣装オブジェクトをアバターのルートの子に作る（最後に体のオブジェクトの下へ移す。下記 5）。
2. アーマチュアの複製: アバターの骨組み（3.1）以下で、体のボーン（3.1 の読み替え後）とルートボーンへの経路上にある物だけを、名前・ローカル変換を保って複製する。複製の最上位は元と同じワールド位置・回転に置く。体が自分の骨組みを持つ場合、そのボーンは読み替え先の複製に対応させる。
3. 布のレンダラー: 体のレンダラーと同じワールド位置・回転・スケール（衣装オブジェクトのスケールで割る）に置く（メッシュが体のメッシュ空間にあるため）。
   ボーン・ルートボーンは複製へ差し替え、ローカル境界・プローブ・影・オフスクリーン更新の設定を体から写す。シェイプキーの値を写し、MA Blendshape Sync を付ける。
4. 肌の写しのレンダラーも同様に作る。
5. 衣装オブジェクトを、体のレンダラーのオブジェクトの子へ、ワールドの位置・回転・拡大率を保って移す（1.2 の条件を満たすとき）。
6. Modular Avatar の Setup Outfit を衣装オブジェクトにかける。
7. 姿勢による透けを使うマテリアルがあれば、7.5 のデータを布のメッシュに入れる。

## 7. 見た目

### 7.1 メッシュの UV チャンネル

| チャンネル | 内容 |
|---|---|
| UV0 | x: 伸びのマスクの値 v（7.4）を `0.02 + 0.96 × clamp01(v)` で写した物、y: 0.5 |
| UV1 | 柄のテクスチャ座標 `(u / 4, (s + 1.5) / 5)` |
| UV3 | x: 姿勢による透けの係数 k（7.5、使うときだけ） |
| UV4 | 脚の座標 (s, u) |
| 接線 | 姿勢による透け用の「縮みを測るベクトル」（使うときだけ。それ以外は通常の計算値） |
| サブメッシュ | 部位ごと（使われた部位だけ、部位番号順）。2 層式は先頭に全三角形の裏地のサブメッシュ |

### 7.2 部位ごとの編み方

部位ごとに 1 つのマテリアル（最大 8、2 層式は裏地を加えて 9）。半透明では部位の被覆率を `1 − (1 − c)^k` にし、色に係数を掛ける。

| 部位 | k | 色の係数 |
|---|---|---|
| 脚・上部 | 1 | 1 |
| パンティ部 | 1.6 | 0.97 |
| 帯・ソックスの帯 | 3 | 0.85 |
| 縫い目 | 3 | 0.75 |
| ひしマチ | 2 | 0.82 |
| 補強（補強） | 2.2 | 0.9 |
| 補強（サンダル） | 1.3 | 0.97 |

### 7.3 マテリアル（lilToon）

- **不透明な編み地**: lilToon 不透明、色 = 編み地の色 × 係数、裏面カリング。
- **半透明な編み地**: lilToon 半透明、色同上、
  - 2nd テクスチャに「角度による透け」テクスチャ（128×128、リニア）を MatCap UV で読み、アルファを置き換える。
    テクスチャは中心からの半径 r（MatCap の半径 = sinθ）で、`1 − (1 − c')^(1 / √(1 − r²))`（c' は部位の被覆率、r² は 0.9999 で上限）。
  - Cutoff を 0.001 にする（lilToon の半透明でも既定 0.5 で切られるため）。
  - 実効の伸びの強さ > 0 かつ「引っ張りで透ける」でないなら、アルファマスク（乗算）に「UV0.x の値をそのまま返すランプ」（256×4、リニア、クランプ）を使う（アルファ × 伸びのマスク）。
  - カスタムシェーダー（7.5）があれば差し替える。_LWDynamicStretch = 姿勢による透けを使わないなら 0、引っ張りで透けるなら実効の強さ、それ以外は 1。
- **2 層式**: 先頭に裏地（不透明、裏地の色、裏面カリング、Offset +1）、続いて部位ごとの表地（見かけのデニールの半透明）。裏地と表地は同じ三角形を重ねて描く。
  形の厚みと肌の削除は「デニール」に従う（裏地が肌を隠すので不透明扱い）。肌の写しは使わない。
  **裏地の色を肌から取る**: 体のサブメッシュのうち脚ウェイト 0.9 以上の頂点を最も多く含む物のマテリアルについて、メインテクスチャを 128×128 に縮小して、
  それらの頂点の UV（小数部）で双線形に読んだ平均 × マテリアルの色（不透明）。テクスチャが無ければマテリアルの色、マテリアルが無ければ手動の色。
- lilToon が無ければ Standard シェーダーで色 × 係数だけ（透けなし）。

フェイクサイハイの部位の編み地: 上部・パンティ部・帯・縫い目・ひしマチは「上部」の編み地（上部のデニール・上部の色。透けるかは上部のデニールで判定）、
脚・補強・ソックスの帯は通常の編み地。

### 7.4 伸びによる透け（立った姿勢の固定分布）

実物は伸びた所ほど編み目が開いて透ける。伸び率 s のとき被覆率は c/s とみなし、透明度に 1/s を掛ける。Blender で頂点ごとに求める（stretch_mask）。

- 左右の脚それぞれで、各頂点の脚の鎖パラメータ t と鎖までの距離 r を求める。0 ≤ t ≤ 2 の頂点が 10 個以上あるときだけ計算する。
- 太さの比 q = r / （0 ≤ t ≤ 2 の頂点の r の 10 パーセンタイル）。
- 太さの項 `1 + 0.25 × max(q − 1, 0) × fade`。fade = clip(t / 0.15) × clip((2 − t) / 0.15)（腰と足では 0。実物の補強部分は伸びなし）。
- 膝の前: `0.35 × exp(−((t − 1) / 0.15)²) × clip(法線·前方向)`（前方向は足首→つま先のボーン、無ければ up × lateral）。
- s = 太さの項 + 膝の前。隣と半分ずつ混ぜる平滑化を 4 回（左右・部位の継ぎ目をなくす）。
- 強さ σ を掛けて s = 1 + σ (s − 1)。出力は clip(1/s, 0.3, 1)。σ が 0 なら全頂点 1。
- 腕の衣類は 8.3 の別の式。

### 7.5 姿勢による透け（PC のみ。カスタムシェーダー）

膝を曲げると膝の前が透け、膝裏・脚の付け根の折れ目が濃くなる。

**原理**: 線形ブレンドスキニングは、ウェイトが混ざる頂点でベクトルを曲がりに応じて短くする。そこで各頂点に「立った姿勢でスキニングすると長さ 1 になるベクトル」を接線として入れておき、
シェーダーでスキニング後の接線の長さを測れば、その頂点の曲がり c = 1 − |接線| が分かる。

**生成時のデータ**（PoseStretch.Store。脚の衣類のみ）:

1. 接線: アバターの上方向をメッシュ空間にした単位ベクトル u を、立った姿勢でスキニングした長さ L で割った `u / L`（w = 1）。
2. 布のアーマチュアの複製で脚を曲げる: 太もも 70 度（前へ）、すね 100 度（後ろへ）、足 30 度（つま先を下へ）。回転軸は `上 × 前`。
3. 各頂点の周りの三角形面積の和を、立った姿勢と曲げた姿勢で比べる（スキニングはルートボーンの空間、スケールなし。シェーダーが見る空間）。
4. c ≥ 0.01 の頂点で `k = clamp((面積比 − 1) / max(c, 0.05), −12, 12)`（膝の前で正、膝裏で負）。
5. 隣と `(自分 + 隣の平均) / 2` の平滑化を 3 回（粗いメッシュで関節に三角形の形の斑が出ないように）。UV3.x に保存。

**シェーダー**（lilToon のカスタムシェーダー `LegWeaver/Transparent`。見た目は lilToon の半透明と同じで透明度の計算だけを足す）:

- 頂点: `s = 1 + UV3.x × (1 − |スキニング後の接線|)`。三角形の中で補間する（三角形ごとの段にならない）。
- フラグメント（アルファマスクの前）: _LWDynamicStretch > 0 なら `alpha = saturate(alpha / clamp(s, 0.92, 3)^_LWDynamicStretch)`（縮む側を 0.92 で止める: 実物の編み地は面積が縮んでも詰まらず、しわになって逃げる。補強の部位はもともと濃いので、これより下げると足首を伸ばしたときのかかとがほぼ不透明な黒になる）。
- **奥行きの先行パス**: 色を書かず深度だけを書くパスを先に描く（ZWrite オン、同じカリング）。布が自分と重なって見える所（股を下から見るなど）で、半透明の三角形が描画順で
  混ざって濃淡のまだらが出ないよう、一番手前の層だけが描かれる。このシェーダーは姿勢による透けがオフでも半透明の布すべてに使う。描画キューは AlphaTest + 10。
- Android（Quest）ではカスタムシェーダーが使えないため対象外。

**引っ張られた所の透け（不透明）**: 2.2 の「引っ張りで透ける」とき、見た目の被覆率を 1 にして半透明のマテリアル（角度による透けも 1）で描き、
姿勢による透けの指数に実効の強さを使う。立った姿勢では完全に不透明で、曲げた所だけ透ける。静的な伸びのマスクは使わない。肌の写しを使い、下着の上も写しで覆う。

キャットタイツ（7.8）の上部のマテリアルは、伸びによる透け・姿勢による透けを切る（耳がソックスの延長なので、透けると耳が薄れる）。

### 7.6 質感（lilToon の設定）

標準は lilToon の既定のまま。それ以外は影・反射・リムライトを次のように設定する（角度による濃さと伸びの透けはそのまま効く）。

| 質感 | 影の強さ / ぼかし | なめらかさ | 反射率 | トゥーンの鏡面 | リム（強さ / 境界 / ぼかし） |
|---|---|---|---|---|---|
| マット | 0.45 / 0.5 | 0.25 | 0.02 | なし | なし |
| セミグロス | 0.45 / 0.5 | 0.55 | 0.04 | なし | 0.25 / 0.5 / 0.6 |
| 光沢 | 0.45 / 0.5 | 0.75 | 0.08 | なし | 0.4 / 0.5 / 0.6 |
| サテン | 0.45 / 0.5 | 0.9 | 0.16 | なし | 0.6 / 0.5 / 0.6 |
| トゥーン | 0.6 / 0.03 | 0.7 | 0.06 | あり | 0.35 / 0.6 / 0.05 |
| 綿（手袋のみ） | 0.45 / 0.5 | — | 反射なし | — | なし |

影はすべて有効・境界 0.5。反射ありは金属度 0・鏡面を適用。リムの色は白（アルファ = 強さ）。

### 7.7 柄・テクスチャ（LegPattern）

#### 7.7.1 テクスチャを付ける条件

部位のマテリアルに柄のテクスチャを付けるのは、次のどれかのとき:
ソックスで口ゴムが無地でなく部位が帯／グラデーション／伝線 1 本以上／バックシームで部位が補強以外／ドット・猫で部位が脚／
フェイクサイハイで境目の飾りがあり部位が上部かソックスの帯／キャットタイツで部位が脚。

テクスチャは 2048×2048（ミップマップあり、u は繰り返し・v はクランプ）。横 = 脚の周りの回転数 0〜4（左脚 0〜2、右脚 2〜4。各脚で使うのは 1 回転分）、
縦 = s を −1.5〜3.5 に写した物。lilToon の 3rd テクスチャとして UV1 で読み、通常合成、半透明なら「アルファ加算」（柄は濃く編んだ部分）、不透明なら色だけ。

#### 7.7.2 画素の値

各画素の (s, u, 右脚か) について:

1. 基本色: 編み地の色 × 部位の係数。グラデーションなら `smoothstep(InverseLerp(上, 下, s))` の割合で「下の色」へ。
2. 柄の濃さ d（0〜1）: 柄を入れる脚（両脚／左／右）だけ。足の手前で消す係数 feet = Smooth(1.9 − s, 0.06)。
   - バックシーム（補強以外の部位）: `Smooth(0.005 × 大きさ − |u − 0.5|, 0.0015) × feet`（脚の後ろ中央の線。足首の少し上からウエストまで）。
   - ドット（脚の部位。フェイクサイハイではソックス部 s > 境目だけ）: 1 周に round(14 / 大きさ)（最低 2）個、s 方向に 0.07 × 大きさごとの行、奇数行は半個ずらす。
     各セルの中心からの距離 ρ（セル幅で正規化）で `Smooth(0.27 − ρ, 0.03)`。× feet。
   - 猫: 同じく 1 周 round(8 / 大きさ) 個、行 0.12 × 大きさ。猫の頭（中心 (0, 0.05)、半径 0.25、縦を √1.2 倍に詰めた円、ぼかし 0.02）と
     2 つの三角の耳（頭の上、股関節側へ）から、目（(±0.09, 0.02) 半径 0.045）を抜いた形。× feet。
   - フェイクサイハイの境目の飾り（7.8）と最大をとる。
3. 色 = 基本色から「柄の色」（上部の部位では布の色＝ソックスの色）へ d の割合で混ぜる。
4. ソックスの帯: レースなら網目 Net(s, u, 56, 0.014) × 0.75 の割合で肌の色へ（穴から肌が見える）。
   滑り止めなら波 `s / 0.01 + 0.25 sin(2π · 14u)` の整数からのずれで `0.25 × Smooth(0.18 − ずれ, 0.05)` の割合で白へ。
   Net(s, u, n, a): x = (u·n の小数部) − 0.5、y = (s/a の小数部) − 0.5、`Smooth(0.3 − √(x² + y²), 0.05)`。
5. キャットタイツの顔（脚・ソックスの帯の部位）: 境目からの下がり量で、上部の色の目・鼻・ひげを描く（7.8）。
6. 伝線: 色を肌の色へ `伝線の濃さ × 0.7` の割合で混ぜる。
7. アルファ: 半透明なら `d × 柄の濃さ`（キャットタイツの上部では d × 1）、不透明なら 1。

肌の色は 7.3 の「裏地の色を肌から取る」と同じ推定（失敗時は裏地の手動の色）。

#### 7.7.3 伝線

種から擬似乱数を作り、本数ぶん（右脚か: 乱数 < 0.5、u0: 乱数、開始 s0: 0.2 + 乱数 × 1.4、長さ: 0.15 + 乱数 × 0.5）を順に引く。
乱数は SplitMix64 で、状態の初期値は種（32 ビット符号付き整数を符号なし 32 ビットとして 64 ビットに広げた値）。1 回ごとに
状態 += 0x9E3779B97F4A7C15、z = 状態、z = (z ^ (z >> 30)) × 0xBF58476D1CE4E5B9、z = (z ^ (z >> 27)) × 0x94D049BB133111EB、z ^ (z >> 31)
を 64 ビットの符号なし整数で計算し（掛け算は 2^64 で折り返す）、乱数 = (z >> 11) / 2^53 とする。
（同じ種なら、どの言語の実装でも同じ配置になる。）

### 7.8 フェイクサイハイ

1 枚のタイツで、太ももの境目より下をソックス部（デニール・色に従う）、上を素肌が透ける薄いストッキング部（上部のデニール・上部の色）にする。

- 境目: 左右の脚の鎖 s = 境目の高さ（0.15〜0.95）の点で、股関節側が上部。5.6 で布を平面で切り分ける。帯がオンなら境目から下へ leg_len × 3.5% をソックスの帯にする。
- 形・肌の削除の「不透明」はソックス部のデニールで決まるが、Blender へは不透明として渡さない。肌の写しを使わない場合、上部の下の肌は被覆距離を負にして削除しない。
- 2 層式とは同時に使えない。「引っ張りで透ける」も使えない。
- 境目の飾り（上部・ソックスの帯の柄テクスチャに描く。色はソックスの色）。境目からの上がり量 above = 境目 − s:
  - **レース**: 1 周 16 個の半円の縁。上部では x = (16u の小数部) − 0.5、e = √(4x² + (above / 0.06)²) として
    `Smooth(1 − e, 0.06) × (1 − 0.7 × 穴)`、穴 = Net(s, u, 72, 0.018) × Smooth(0.75 − e, 0.05)。ソックスの帯では `1 − 0.5 × Net(s, u, 72, 0.018)`。
  - **波**: 上部で、峰の高さ `0.035 × (0.5 + 0.5 cos(2π · 7u))` として `Smooth(峰 + 0.004 − above, 0.003)`（ソックスが波形に伸び上がる）。
  - **猫**: 各脚の前（前から ±0.5 回転の x）に猫の顔。大きさの基準 1.7 で above と x を割った値で、
    耳は左右の三角形（高さ 0.085、底辺の半幅 0.042、中心 ±(0.066 + 0.01 t)、内側に小さな透けた三角）を上部に、
    顔（目: (±0.045, 0.07) の縦長の楕円 0.013×0.02、鼻: 0.098 から下向きの小三角、ひげ: 片側 3 本の扇形の線）をソックス部に上部の色で描く。
    耳の濃さは柄の濃さによらず 1。

### 7.9 脚の座標

- s: 脚の鎖のパラメータ（股関節 0、膝 1、足首 2、つま先 3。股関節より上は負）。
- u: その区間の軸の周りの角度（回転数）。基準は前方向を軸に直交化した方向で 0。左右で外側が同じ向きになるよう、角度に左右の符号を掛けて反転する。
  左脚は 0〜1、右脚は +2 して 2〜3。
- 柄は脚の周りの角度で並ぶので、細い所（足首）ほど小さくなる。

## 8. 腕の衣類（手袋・アームカバー）

脚と同じ方式（体のメッシュをずらして布にする）で作る。違いは次のとおり。

### 8.1 切り出し

腕ごとに、手首の位置・前腕方向 d（肘→手首）・手の到達を求める。手の到達は、手首より先（d 方向への射影が正）にあるその側の点のうち、中指の付け根（無ければ手首）に最も近い点と、手首より先の点どうしの辺でつながる点だけについての、d 方向への射影の最大（腕を下げた体では、手首より先に同じ側の脚もあるため）。正でなければ前腕の長さ × 0.7。
「指の付け根の手前」knuckle = 中指の付け根 − d × 到達 × 0.18（無ければ 手首 + d × 到達 × 0.3）（関節の上に縁を置くと、拳を握ったとき肌が出るため手前で止める）。

| 種類 | 平面 | 種 |
|---|---|---|
| 手袋 | 上端: 腕の鎖 s = 長さ（手首 1.92／前腕 1.5／肘上 0.55）、手先側を残す。指なしなら knuckle の切り取りと親指の穴（8.1.1）を追加。絵描き用なら、親指の穴と指の側の切り取りを 1 つの滑らかな形（8.1.1）で切る | 手首 + d × 到達 × 0.2 |
| アームカバー | 上端: 腕の鎖 s = 上端の位置、手先側を残す。「手の甲まで」なら knuckle の切り取りと親指の穴（8.1.1）。そうでなければ s = 1.97 で肩側を残す | 腕の鎖 s = 1.5 |

連結成分は種を含む物だけを残す（無限平面は下げた腕の高さで脚の一部も通すため、脚ウェイトによる追加はしない）。全頂点が残した面から 8 mm 以内にある成分（指から離れた島になっている爪など）は布にせず、その各点の最も近い残した面の頂点に、面の法線方向の高さを記録し、布を肌から少なくとも offset + その高さ（頂点の値を重心座標で補間）だけ離す（持ち上げと、その後に強制する床の両方）。

#### 8.1.1 滑らかな形で切る

平面に制限（球の中など）を付けて切ると、制限の境目で三角形の形のまま段になる。親指の穴と絵描き用は、およその符号付き距離 f（正なら残す）で表し、
f の符号が変わる辺を f = 0 の所（二分法 30 回）で分け、分けた点どうしを面の中でつないでから、頂点の f の平均が負の面を削除する。

- 親指の楕円体: 軸 u = 親指の付け根→中間の関節（長さ L）。太さ = 付け根から 0.6〜1.0 L で軸から 1.2 L 以内の体の点の、軸からの距離の中央値
  （8 点未満なら 0.5 L）、半径 r = max(0.55 L, 太さ × 1.6)。先 = 付け根から 6 L 以内・軸から太さ × 1.2 以内の点の u 方向の最大 + 0.3 L
  （2.55 L 以上）。楕円体は u 方向に 0.25 L から先まで、太さ方向の半径 r。f = (√((x/a)² + (y/r)²) − 1) × r。
- 絵描き用: 指の側の切り取り量 = smin((p − 付け根の中点)·fd, (p − 仕切りの点)·across, k)。fd = 中指の付け根→中指の先の関節（無ければ d）、
  仕切りの点 = 中指の付け根 − (人差し指 − 中指の付け根) × 0.5、across = (人差し指 − 中指の付け根) の fd に直交する成分の向き、
  k = 人差し指と中指の付け根の間 × 0.5。親指の穴と smax(·, −f親指, 到達 × 0.15) で合わせ、f = −その値。smin は半径 k で角を丸めた min
  （smax はその符号を反転したもの）。人差し指か中指の付け根が無ければ親指の穴だけ。
- knuckle の切り取り（指なし・手の甲まで）: smax((p − knuckle)·d, −f親指, 到達 × 0.15)、f = −その値（平面が親指の付け根を斜めに横切ると、親指の股に尖った布が残るため、親指の穴と丸めて合わせる）。親指の骨が無ければ平面だけ。
- 範囲の穴をふさぐときの「縁の上にあるか」は、平面では |(p − co)·n|、滑らかな形では |f| で判定する。

### 8.2 形

- 足先の SDF・お尻の橋渡しは行わない。指は体の指に沿って包み、指のボーンのウェイトで指ごとに曲がる（5 本指）。
- 部位: 上端の帯（ウエストバンドの設定）だけ。補強・パンティ部・股の部位は無い。
- 手の指の骨（中指の付け根・親指）は Humanoid の設定から取る。中指が無ければ knuckle を手首と手の到達から決め（8.1）、親指が無ければ親指の穴は作らない。
  肩（UpperArm）か手（Hand）が無い腕は作らない。

### 8.3 伸びによる透け（腕）

脚の式（7.4）と同じ構造で、腕の鎖を使う:

- 太さの項: 0 ≤ t ≤ 2 の頂点が 10 個以上あるとき `1 + 0.25 × max(q − 1, 0) × fade`（手首より先は太さの項なし）。
- 肘の後ろ: `0.35 × exp(−((t − 1) / 0.15)²) × clip(法線·(−前方向))`。
- 拳の甲（腕の鎖に中指があるとき）: `0.3 × exp(−((t − 3) / 0.12)²) × clip(法線·up)`（静止姿勢で手のひらが下向きの前提）。
- 平滑化・強さ・出力は脚と同じ。

姿勢による透けは使わない（腕の伸びは骨の継ぎ目に出て、脚に沿った接線の縮みでは捉えられない）。静的な分布だけを使う。

### 8.4 その他

- 質感に「綿」（つやなし）を選べるのは手袋だけ。
- 肌の削除・肌の写しは脚と同じ規則で行う。箱の当てはめ（6.5）は脚と骨盤の鎖を前提にしており、腕の頂点（股関節より上）は骨盤の水平な薄切りと補いの箱で覆われる。

## 9. 包む（脚の代わりの下半身）

脚の代わりに別の下半身（おばけのしっぽなど）へ切り替えるアバターのための種類。Blender を使わず、Unity 側だけで作る。

### 9.1 包むメッシュの選び方（WrapGarment.Candidates）

手動指定が無ければ、アバター配下の SkinnedMeshRenderer（非表示も含む）のうち、次を全て満たす物を候補とする:

- 体（3.1）でも、本ツールの生成物でもない。
- ウェイトの 80% 以上が、Hips かその子孫のうち、脚（左右の UpperLeg 以下）でも背骨（Spine 以下）でもないボーン（3.1 の読み替え後）にある。
- 今の形（シェイプキー・姿勢を反映したワールド座標）の上端が Hips の高さ + 太ももの長さ × 0.3 以下、下端が Hips の高さ − 太ももの長さ × 0.5 以下で、
  かつ左の LowerLeg（膝）より低い（下着やフリルのような短い物を除く）。
- 脚を囲む: 左右の UpperLeg の中点から見て、左右方向（左右の UpperLeg を結ぶ向き）に両脚の付け根より外まで広がり、
  前後方向（左右方向と上の外積）にも前と後ろの両方へ脚の間隔 × 0.25 以上広がる（後ろにだけ垂れるしっぽや、細い物を除く）。
- 開いた縁（位置で溶接して、1 つの三角形にしか属さない辺）の頂点が、全て上から高さの 1/3 以内にある（下が閉じている。裾の開いたスカートを除く）。

候補のうち上下の長さが最大の物を使う。見つからなければ止める（ウィンドウで指定する）。

### 9.2 形

- 包むメッシュの頂点ごとに、同じ位置の頂点の法線（単位ベクトル）の合計を求める。合計の長さが「頂点の数 × 0.2」を超えればその向き、
  超えなければ（薄いひれの縁など、法線が打ち消し合う所）その頂点自身の法線の向きに、`(隙間 + 布の厚み)` だけずらす。
- メッシュの単位への換算は、各ボーンの `ワールド行列 × バインドポーズ` の拡大率（x 成分）の中央値で割る（姿勢やシェイプキーに左右されない）。
- 三角形・ボーンウェイト・バインドポーズ・シェイプキー（全フレーム）は包むメッシュのものをそのまま使い、サブメッシュは 1 つにまとめる。
- UV0 は伸びの透けなし（7.4 の値 1）、UV1 は 0。

### 9.3 見た目と組み立て

- マテリアルは脚の部位（Leg）の編み方で 1 つ作る（7.3）。姿勢による透け・柄・グラデーション・伝線・2 層式・引っ張りの透けは使わない。
- 包むメッシュのオブジェクトの子に置き、同じボーン・ルートボーン・描画の設定（6.7 の 3 と同じ）を使い、シェイプキーの値を写して MA Blendshape Sync を付ける。
  包むメッシュのオブジェクトと一緒に表示・非表示が切り替わる。
- 肌の削除・肌の写し・下着の扱いはしない。
